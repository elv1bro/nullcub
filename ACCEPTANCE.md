# Приёмка релиз-кандидата

Открывай этот файл рядом с игрой. По каждому блоку либо ставь `[x]`, либо пиши в чат проблему в формате:

`[где] что вижу -> что ожидал`

Пример: `[бой] удар по врагу не видно, HP скачет -> ожидал отдачу и вспышку`

Пока блок не закрыт — дальше не идём.

## Как открыть игру

- Компьютер: [http://localhost:5199/](http://localhost:5199/)
- Телефон / любой интернет: [http://138.201.50.89:8080/](http://138.201.50.89:8080/)
- Телефон (домашний вайфай, если local-dev): [http://192.168.0.190:5199/](http://192.168.0.190:5199/)
- Приложение: `env -u ELECTRON_RUN_AS_NODE yarn electron:play`
- Если страница не открывается локально: `yarn dev:lan`

В левом верхнем углу всегда виден **счётчик FPS** (зелёный ≈ 60, жёлтый ≈ 30–54, красный ниже 30).

## G1. Меню и первый запуск

**Что сделать:** 30 секунд смотри на главное меню ничего не нажимая. Потом зайди в каждый пункт и вернись. Повтори на телефоне (портрет и альбом).

- [x] Понятно, что это за игра и куда жать главную кнопку
- [ ] Нет пунктов, которые никуда не ведут / «скоро» / пустые экраны
- [ ] Из любого экрана можно вернуться в главное меню (в т.ч. мастерская — кнопка «← Назад»)
- [x] Ничего не просит камеру / микрофон на старте
- [ ] На телефоне кнопки удобно жать пальцем, меню не обрезано — открыть [н](http://138.201.50.89:8080/)
- [x] FPS в меню видно и обычно ≥ 50
- [ ] Управление: понятно что делает каждая клавиша, игрок 1 и 2 рядом; сброс клавиш только там

**Замечания (прошлый проход):** сброс клавиш был в настройках; мастерская — только стрелка; телефон без публичной ссылки.

**Что сделать:** Главная → В бой → Против бота. Сыграй ровно один бой до экрана итогов. Смотри FPS в углу.

- [ ] Видно, когда ты попал по врагу
- [ ] Видно, когда попали по тебе
- [ ] Понятно, почему бой кончился
- [ ] Бой заканчивается сам (не зависает)
- [ ] После итогов есть путь назад в меню

- [ ] FPS в бою обычно ≥ 50 (на телефоне допустимо ≥ 30; если красный — напиши модель устройства)

## G3. Управление

**Что сделать:** В бою против бота / локально 2 игрока.

### Один игрок (против бота)

- [ ] WASD двигает только твоего бойца
- [ ] Стрелки **не** двигают твоего бойца (они для второго игрока)
- [ ] Короткое нажатие влево и вправо дают похожий сдвиг
- [ ] Если ничего не нажимать — боец не уползает сам вбок

### Локально · 2 игрока

- [ ] WASD двигает только синего / первого
- [ ] Стрелки двигают только второго
- [ ] Никакие клавиши не двигают обоих сразу

### Телефон

- [ ] В портрете есть подсказка повернуть (ширина > высоты)
- [ ] В бою слева виртуальный стик — палец ведёт бойца
- [ ] Справа кнопка рывка срабатывает по нажатию
- [ ] Страница не ездит и не зумится во время боя
