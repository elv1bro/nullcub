02.10.2026 автор: «сделай всё мультиязычным, язык в настройках, пока русский и английский, но чтобы легко добавить любой». Слито в main и запушено 02.10 (2765e63); устройство и глоссарий — `docs/plan-demo/I18N.md`.

- Ключ перевода = русская строка из кода дословно (`tr("Начать бой")`), английские подписи табло — `tr("FIGHT!")`. ru — исходный язык, словарь ему не нужен (`project.godot`: locale/fallback=ru, иначе движок покажет английский).
- Языки — файлы `godot/locale/<код>.json` (`@name` — родное название), автозагрузка `Loc` сама находит их; новый язык: `python3 godot/tools/i18n.py new de Deutsch`. Нет строки → английская → русская.
- Строка «ЯЗЫК» первая в НАСТРОЙКАХ гаража (`Flow` → `lang` в `user://settings.cfg`), смена перезагружает гараж.

**Why:** автор хочет добавлять языки без правок кода; код остаётся русским, как в остальном проекте.
**How to apply:** новый видимый игроку текст — только через `tr()` (в static — `TranslationServer.translate`), не в `const` (там перевод в месте использования), логику не строить на тексте (коды), склейки заменять форматом; после правок `python3 godot/tools/i18n.py check` и `tests/i18n_probe`, `tests/i18n_scenes_probe`; английский перевод новой строки — в `locale/en.json`. Термины — глоссарий в I18N.md. См. [[port-in-game-language]], [[keys-no-f-keys]].
