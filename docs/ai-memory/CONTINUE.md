## Правила работы

- Godot: первый запуск — `godot --headless --path godot --import` (несколько минут). Обёртка блокировки из локальных сессий в облаке не нужна.
- В облачном контейнере Blender и Godot не стоят, ставятся так (30.09, ~2 мин):
  - Blender: `curl -sSL https://download.blender.org/release/Blender4.5/blender-4.5.9-linux-x64.tar.xz | tar xJ -C /opt/tools` и ссылка `/usr/local/bin/blender`;
  - Godot: `curl -sSL -o godot.zip "https://downloads.godotengine.org/?version=4.7.2&flavor=stable&slug=linux.x86_64.zip&platform=linux.64"`, затем unzip и ссылка `/usr/local/bin/godot`; github.com для релизов закрыт прокси;
  - снимки из окна: `apt-get install -y mesa-vulkan-drivers` (lavapipe), затем `xvfb-run -a -s "-screen 0 1600x900x24" godot --path godot …`;
  - системному python3 для листов нужны `pip install numpy pillow`.
- Лор: всё новое помечать «предложение», пока автор не принял. Правило мира — «сюжет создаёт геймплей»: факт без механики не выходит на экран.
