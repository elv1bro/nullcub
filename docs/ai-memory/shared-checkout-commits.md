В ragdoll-faces одновременно работают 3–5 сессий Claude в ОДНОМ чекауте (общий git-индекс). 29.09 боевая сессия сделала обычный `git commit` через секунды после моего `git add` и забрала 87 чужих подготовленных файлов; пришлось делать reset --soft и перекоммит.

**Why:** `git add` + отдельный `git commit` в разных вызовах — окно гонки; плоский `git commit` берёт всё, что кто-то подготовил.
**How to apply:** коммитить одним bash-скриптом: `git add -- "${P[@]}" && git commit -F msg -- "${P[@]}"` (path-limited = --only, чужой индекс не захватывается); в zsh/fish переменная со списком путей не бьётся на слова — использовать bash-массив. Перед коммитом спросить владельцев чужих файлов (автор 29.09: «после работы договорись со всеми и закоммить всё»). Историю не переписывать, пока другие сессии работают поверх main. См. [[godot-test-workflow]], [[body-kit-v2]].
