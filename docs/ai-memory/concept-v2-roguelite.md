**28.09.2026:** автор развернул Ragdoll Master из PvP party-файтинга в **кооперативный PvE physics roguelite** (1–4 игрока, экспедиция вверх по Башне, тело из деталей на anchors с бюджетом Energy, крафт меняет физику, а не цифры). Тексты автора дословно: `docs/plan-demo/CONCEPT_V2.md` (замысел) и `docs/plan-demo/LORE.md` (Башня, Ядро, Корона, The Scrap, UNKNOWN CORE, текст финала, который автор потом снял). Решения автора: PvP = «Быстрая игра» (выбор карты → бой, всё из этапа 06); friendly fire — настройка забега; **летаем, не ходим** — форма тела не важна, ноги = масса и рычаг. Лор: несерьёзный тон, под ним загадочный мир. Лицо — наклеенная фотография (сфоткался → вырезали → на голову), это же ответ лора «зачем голова» (картотека Башни с фотокарточками). Инвентарь до 3 спецпредметов, главный — Ядро товарища для возрождения. Пышного финала с выбором нет («одинаковый выбор 100 раз»). 10 биомов Башни — `docs/plan-demo/BIOMES.md` (порядок может меняться); автор пришлёт листы ассетов (по 20 на лист), я перевожу их в 3D Blender-скриптами по требованиям из BIOMES.md.
