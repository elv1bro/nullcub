11.10.2026 по просьбе автора («сделай 1–4, трейлер тоже включи») собрал 0.0.4. Локальный main `a847705` (пакет режимов 06.10, проход по картинке, экран «ВСЕ РЕЖИМЫ») слит с origin/main `64e5ffd` (облако 08–10.10: 5×5, Заражение, Охота за головами, Канат, Царь горы, хоккей, реестр «РЕЖИМЫ», испытание мастерской) в worktree `claude/dialog-status-v0-0-4-2f1543`, затем `--ff-only` в main (`4ce55d1`), тег `v0.0.4`, main и тег запушены в origin, заметки `docs/plan-demo/RELEASE_0.0.4.md`. Трейлер (`godot/tools/trailer/`, `STEAM_TRAILER.md`) закоммичен, видео нет.

Дочинка того же дня («разбери ошибки и собери до конца»), тег `v0.0.4` передвинут на неё: **канат** — бот human тянул Hand_R, а её плечо у обеих команд слева (кукла не разворачивается), синий бот тянулся дальней рукой через корпус и не брал канат; теперь `TugBrain.rope_hand()` + `ArmAssist.set_control_part()` — кисть со стороны каната, `tug_probe` 23/23. **`workshop_probe`** 239/239: энергия human 72 при `PartHp.on` (82 без), касание манекена — после подхода на длину руки.

Исправлено при сборке: 6 «звуков без файлов» — в git оставались `.import` от удалённых в 380abb2 ogg, а `sfx_director.gd make_layer()` подбирает файлы по списку папки → сцена звука не грузилась; «/» — фоторежим против руки P2: группа `PhotoMode.KEY_TAKEN_GROUP` (головоломки, Перегон, Канат с P2-человеком), проба `photo_key_probe`.

**Why:** общая точка отсчёта после двух параллельных линий (локальной и облачной), как [[release-003]].
**How to apply:**
- «Красная на Mac, зелёная в облаке» — не списывать на машину: у `rope_holds_10s` была настоящая причина (дальняя рука), облако проходило на пределе досягаемости.
- Проба мастерской сверяет энергию с режимом `PartHp.on`; если поменяют цену ядра/головы — правят `HUMAN_ENERGY*` в `workshop_probe.gd`.
- Человек P1 слева в Канате по-прежнему тянет Hand_R (ЛКМ) — удобство не проверено руками.
- «Parameter "material" is null» в headless — от заглушки рендера, пробы не краснеют, источник не найден.
- Изолировать пользовательские настройки Godot для пробы: `HOME=<пустая папка> godot …` (user:// уходит в новый каталог).
- Подсчёт SCRIPT ERROR grep'ом ловит строку «SCRIPT ERROR: 0» — смотреть число, не факт совпадения.
