**Решение автора (20.09.2026):** сменить физический движок. Причина: Matter.js ведёт себя очень неестественно, и у автора много вопросов именно к тому, как физика выглядит/показывается на экране. Это решение принято несмотря на рекомендацию панели остаться на Matter — считать его зафиксированным, не переубеждать заново.

**Что показал разбор (workflow 8 агентов, 20.09.2026):**
- В Matter нет шарниров с угловыми лимитами, моторов, верёвок, CCD; суставы стикмена эмулируются парами дистанционных пружин (`src/utils/createStickman.ts:38-127`), поза держится покадровыми силами, солвер выкручен до 12/8/6 итераций. ~26 обходов, 10 из них чисто из-за Matter.
- Абстракции физики нет: Matter.Body/Composite = модель сущностей; ~164 файла / ~29k строк завязаны на Matter, 592 вызова API, userdata в body.plugin и label === "Head".
- Оценки для одного разработчика: замена движка внутри TS (Rapier2D или Box2D v3 wasm) за фасадом — 8–13 недель; переписывание на Godot 4 + Jolt на плоскости — 22–34 недели, плюс потеря веб-канала (6 МБ экспорт против 439 КБ), вебки на Windows (GDMP один мейнтейнер) и всего тест-контура.
- Ранее Rapier2D уже пробовали и отвергли по feel («мягкие пружины не давали feel форка», docs/ARCHITECTURE.md:346); следов кода нет. Feel форка = мягкий солвер Matter, жёсткий движок даст другое ощущение.
- Судья-инженер советовал для спайка Box2D v3 (soft-step, hertz/dampingRatio на суставах), а не Rapier.

**Why:** Автор хочет естественную физику; панель зафиксировала цену и порядок работ, чтобы переезд не превратился в переписывание с нуля.

**Урок 29.09 (git при нескольких сессиях в одном дереве):** в общем индексе могут лежать чужие подготовленные файлы — обычный `git commit` их забирает. Коммитить только `git commit --only -m … -- <свои пути>` (или проверять, что `git diff --cached` пуст). Godot под общей блокировкой других сессий: обёртка godot_locked.py (flock на общий godot.lock); новый class_name требует `--import` сразу. Перед новыми приватными членами Doll сверять имена с scripts/body/modular_doll.gd (коллизия `_com_local` ломала всех).

**How to apply:** Работать по `docs/plan-demo/`, начинать диалог с README и нужного этапа. Порядок MVP из CONCEPT.md §27 важнее нумерации этапов. Никаких примитивов Godot, плоских материалов и самописных glTF-генераторов в игре. В Bash всегда абсолютные пути (cd в цепочке ненадёжен; `godot --path` без project.godot виснет). Порядок: 1) remote + коммиты; 2) дешёвая половина фасада без смены движка (Map метаданных вместо body.plugin, Vec2 вместо Vector.*, один модуль settle/grace); 3) спайк `?lab=physics` стикмен на суставах с лимитами, гейт = 4 проверки eval:behavior + слепой A/B; 4) фасад и новый движок за флагом VITE_PHYSICS. Вырезать выключенное (grab, legacy useHealth, 4FFA, P2P, ad-пробник) до порта. См. [[project-essence]].
