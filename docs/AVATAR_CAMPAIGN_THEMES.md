# Темы кампаний и аватары

Живой дизайн-док: **10 тематических кампаний**, иконки категорий, как игрок получает лица из ростера и **уникальная спецспособность** за прохождение кампании (или её финального босса).

Связанные файлы:
- Ростер лиц: `src/face/avatarPresets.ts`, `src/face/avatarRoster.ts`
- Стабильный выбор врага по сиду: `avatarFaceIdForSeed()` в `avatarPresets.ts`
- Текущая кампания-образец: `src/campaign/bouncer.ts`

---

## Иконки категорий

Для меню кампаний и вкладок в «Облике» — **бейдж 64×64** (canvas, тот же стиль что лица: объём, блик, без квадратной рамки).

| ID | Иконка (бейдж) | Краткий визуал |
|---|---|---|
| `knights` | ⚔️ | Серебряный шлем с забралом, красная лента |
| `robots` | 🤖 | Металлическая голова, неоновые глаза-полоски |
| `beasts` | 🐾 | Лапа + когти на тёмно-зелёном фоне |
| `undead` | 💀 | Череп с зелёным свечением глазниц |
| `demons` | 👹 | Красная маска они с золотыми рогами |
| `cosmos` | 🛸 | Пришелец с антенной и фиолетовым ореолом |
| `swamp` | 🫧 | Капля слизи с пузырьками |
| `pirates` | 🏴‍☠️ | Повязка на глаз + череп на флаге |
| `arcane` | ✨ | Звезда/руна на фиолетовом градиенте |
| `shadow` | 🥷 | Чёрная маска ниндзя, красная повязка |

> **Реализация иконок:** отдельные painter'ы `drawCampaignBadge(ctx, themeId)` или SVG-спрайты в `public/campaign-badges/`. В UI — рядом с названием кампании и фильтром лиц.

## Как игрок получает аватары

Общие правила (можно комбинировать):

1. **Победа в кампании** — открывается весь пул темы (или случайное лицо из пула).
2. **Победа над финальным боссом** — гарантированное «именное» лицо + спецспособность.
3. **Достижение** — «Пройди 3 главы Рыцарей без урона» → редкий вариант.
4. **Случайная награда** — после любого боя 5% шанс на лицо из уже открытых тем.
5. **Сид врага** — в кампании лицо босса всегда одно и то же: `avatarFaceIdForSeed("knights-boss-4")`.

Пул лиц задаётся через `kind` и префикс id:
- `human-*`, `robot-*`, `ninja`, `oni-*` и т.д.
- Кураторские id (`kai`, `bjorn`, `oni`…) — награды за ключевые главы.

## 1. Рыцари (`knights`)

### Описание темы
Средневековый таверный турнир: дебоширы в доспехах, честь кружки, грохот лат. Враги — люди в серебре/стали, иногда «тёмный рыцарь» (ниндзя-палитра).

### Пул аватаров
- `kind: human` — причёски `braids`, `bald`, `short`; тона кожи светлые/средние
- Кураторские: `bjorn`, `marcus`-аналоги, `knight` глава в `bouncer.ts`
- Враги кампании: `avatarFaceIdForSeed("knights-{chapter}")`

### Как получить
| Условие | Награда |
|---|---|
| Глава 1 «Пьяный оруженосец» | Случайное `human-*` (серые/стальные волосы) |
| Глава 3 «Турнир кружек» | `bjorn` или викинг с бородой |
| Финал «Король дебоша» | Уникальное лицо `knight-king` (будущий painter: шлем + забрало приоткрыто) + способность |

### Спецспособность: **Рыцарский таран** (`knight_charge`)
- **Кнопка:** 4-я способность (слот E / отдельная клавиша).
- **Эффект:** 1.5 с неуязвимости к отбросу + рывок вперёд ×2.5 скорости; первое столкновение с врагом — **45 дробящего урона** и сильный knockback.
- **КД:** 14 с.
- **Визуал:** латный блик на голове, след пыли.
- **PvP:** неуязвимость только к knockback, урон проходит.

## 2. Роботы (`robots`)

### Описание темы
Заброшенный завод: конвейеры, искры, ржавые болты. Враги — `robot`, `skull` с LED-глазами, «сломанные» зомби-мехи.

### Пул аватаров
- `kind: robot` — все `robot-*`
- Кураторский: `robot`
- Боссы: неон синий / оранжевый / красный «аварийный»

### Как получить
| Условие | Награда |
|---|---|
| Глава 1 «Сборочный цех» | `robot-2` … `robot-5` |
| Глава 2 «Сбой прошивки» | Красные LED-варианты |
| Финал «Ядро Омега» | `robot` + способность |

### Спецспособность: **Перегрузка** (`robot_overclock`)
- **Эффект:** 3 с — глаза и рот светятся; каждый удар по врагу дополнительно наносит **12 силового урона** (огромный отброс); своя скорость +30%.
- **КД:** 12 с.
- **Визуал:** пульсирующее свечение `accent` цвета робота, искры при контакте.
- **Баланс:** после окончания 1 с «перегрев» — скорость −20%.

## 3. Зверинец (`beasts`)

### Описание темы
Арена диких зверей: рев, шерсть, когти. Коты, лисы, тигры, медведи, совы — каждый уровень свой биом (лес / снег / саванна).

### Пул аватаров
- `cat`, `fox`, `tiger`, `bear`, `owl`, `bunny`, `shiba`, `penguin`, `panda` + все `*-2…` вариации

### Как получить
| Условие | Награда |
|---|---|
| Победа в главе | Лицо зверя этой главы (фиксированный сид) |
| Собрать 8 звериных лиц | Редкий `tiger` золотой |
| Финал «Король клетки» | `bear` + способность |

### Спецспособность: **Рык / Прыжок** (`beast_pounce`)
- **Эффект:** короткий прыжок (импульс вверх-вперёд); при приземлении в радиусе 1.2 корпуса — **25 урона** всем врагам и замедление их на 0.5 с.
- **КД:** 11 с.
- **Визуал:** ударная волна-кольцо, эмоция `angry` на 1 с.

## 4. Нежить (`undead`)

### Описание темы
Кладбище и катакомбы: скрип, туман, светлячки. Черепа, зомби, призраки.

### Пул аватаров
- `skull`, `zombie`, `ghost` + вариации

### Как получить
| Условие | Награда |
|---|---|
| Глава «Склеп» | `skull-*` |
| Глава «Эпидемия» | `zombie-*` |
| Финал «Король мёртвых» | `skull` + способность |

### Спецспособность: **Вампиризм удара** (`undead_drain`)
- **Эффект:** следующие 4 с каждый нанесённый урон **восстанавливает 40%** от урона (кап HP 30% от макс. за активацию).
- **КД:** 16 с.
- **Визуал:** зелёные/фиолетовые частицы от врага к голове.

## 5. Демоны (`demons`)

### Описание темы
Адская таверна: огонь, рога, зубы. Они, тыквы, злые люди.

### Пул аватаров
- `oni`, `pumpkin`, `human` с `mood: angry`

### Как получить
| Условие | Награда |
|---|---|
| Глава «Врата» | `oni-2` … `oni-5` |
| Хэллоуин-ивент | `pumpkin` |
| Финал «Владыка Они» | `oni` + способность |

### Спецспособность: **Адское пламя** (`demon_breath`)
- **Эффект:** конус вперёд 1 с — **18 огненного урона** + поджог 3 с (4 dps). Дистанция ~2 корпуса.
- **КД:** 13 с.
- **Визуал:** `faceEffect: fire` на время каста + оранжевый trail.

## 6. Космос (`cosmos`)

### Описание темы
Инопланетный десант: антенны, НЛО, невесомость. Пришельцы, роботы, единороги как «космическая фея».

### Пул аватаров
- `alien`, `robot`, `unicorn` + тёмные/неоновые вариации

### Как получить
| Условие | Награда |
|---|---|
| Глава «Посадка» | `alien-*` |
| Глава «Орбитальная станция» | `robot-*` неон |
| Финал «Мать корабля» | `alien` + способность |

### Спецспособность: **Гравитационный захват** (`cosmos_pull`)
- **Эффект:** 0.8 с — притягивает ближайшего врага к тебе (силовой тип); при столкновении **22 урона**.
- **КД:** 14 с.
- **Визуал:** фиолетовая линия-луч, искажение вокруг голов.

## 7. Болото (`swamp`)

### Описание темы
Топи и кислотные лужи: лягушки, слизь, аксолотли.

### Пул аватаров
- `frog`, `slime`, `axolotl` + все вариации

### Как получить
| Условие | Награда |
|---|---|
| Глава «Топь» | `frog-*` |
| Глава «Кислотное озеро» | `slime-*` |
| Финал «Матерь слизи» | `slime` + способность |

### Спецспособность: **Разделение** (`swamp_split`)
- **Эффект:** на 2 с создаёт **2 декоя** (прозрачные копии тела, только визуал для врага); реальное тело +15% уклонение (меньше попаданий по HP — опционально −15% получаемого урона).
- **КД:** 18 с.
- **Визуал:** полупрозрачные зелёные силуэты, пузыри.

## 8. Пираты (`pirates`)

### Описание темы
Портовая таверна: ром, повязки, пушки. Люди с бородами, лисы как «хитрый капитан», медведи как «боцман».

### Пул аватаров
- `human` с `beard`, `bald`, `braids`; `fox`, `bear`

### Как получить
| Условие | Награда |
|---|---|
| Глава «Салун» | Бородатые `human-*` |
| Глава «Абордаж» | `fox`, `bear` |
| Финал «Адмирал» | Уникальный `pirate-captain` (будущий painter: повязка + треуголка) + способность |

### Спецспособность: **Залп из пушки** (`pirate_barrage`)
- **Эффект:** 3 ядра в веере (лево / центр / право), каждое **28 колющего урона** при попадании.
- **КД:** 12 с.
- **Визуал:** дымные шарики-траектории от головы (как кунаи, но круглые).

### Пул аватаров

|---|---|

| Глава «Звёздный круг» | `unicorn-*` |
| Финал «Архимаг» | `unicorn` + способность |

### Спецспособность: **Звёздный щит** (`arcane_barrier`)

- **КД:** 15 с.
- **Визуал:** `faceEffect: halo` + фиолетовое кольцо вокруг головы.

## 10. Тени / Ниндзя (`shadow`)

### Описание темы
Ночной двор: маски, дым, шёпот. Ниндзя, люди с ирокезом, тихие убийцы.

### Пул аватаров
- `ninja`, `ninja` вариации (будущие `ninja-*` painter'ы), `human` + `mohawk` / тёмные тона

### Как получить
| Условие | Награда |
|---|---|
| Глава «Двор» | `ninja` |
| Глава «Крыша» | Тёмные `human-*` |
| Финал «Глава клана» | Уникальный `ninja-elder` + способность |

### Спецспособность: **Техника скрытности** (`ninja_stealth`) — *референс для всех тем*

Детальная механика (как просил дизайн):

| Аспект | Поведение |
|---|---|
| **Для врага (сеть / локальный P2)** | Тело атакующего **не рендерится** (или alpha = 0): видна **только голова**. Конечности, торс, оружие скрыты. Коллизии тела **остаются** — иначе чит. |
| **Для владельца** | Своё тело **полупрозрачное** (alpha ≈ 0.35), чтобы ориентироваться. Голова непрозрачная. |
| **Длительность** | 4 с активной фазы. |
| **КД** | 16 с. |
| **Атака: Тройное кунаи** | Отдельная кнопка (или вторая фаза после стелса): 3 снаряда в **−45° / 0° / +45°** от взгляда головы. |
| **Урон кунаи** | **30** колющего за попадание (каждое кунаи отдельно). |
| **Скорость снаряда** | Быстрая, дистанция ~4 корпуса. |
| **Визуал** | Тёмный след + красная повязка на лице светится; кунаи — серые треугольники с `trail`. |

**Технические заметки для реализации:**
- Флаг `stealthActive` в `battleSession` / `useBattleOverlay`.
- Рендер: `renderBodyAlpha` для локального игрока; для оппонента `hideRemoteBodyParts` кроме `head` label.
- Синхронизация по сети: пакет `ability: ninja_stealth` + `ability: kunai_burst` с углами.
- Не путать с полным отключением коллизий — только визуальное скрытие.
