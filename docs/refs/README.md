# Референсы

Формат строки: `Rxx-a | краткое имя | статус: комментарий`

Все файлы ниже сгенерированы скриптом `gen_refs.py` (векторные схемы, SVG + PNG). Это **технические** референсы: пропорции, размеры, планировка, палитра. Живописных концептов в стиле картинки-образца здесь нет: их можно сгенерировать в любом генераторе по промптам из `docs/plan-demo/01-references.md`, приложив соответствующую схему как образец компоновки. Перегенерация: `python3 docs/refs/gen_refs.py` (нужен `rsvg-convert`).
