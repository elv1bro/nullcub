# NULL GRAVITY — тестовая сборка 0.0.3 (03–05.10.2026)

Третья общая сборка: в `main` слита работа всех параллельных сессий после 0.0.2. Живёт в ветке **`main`** (тег `v0.0.3`). Это по-прежнему не готовое демо, а сборка для тестирования автором: новые режимы — пробные, руками их ещё никто не играл.

## Как запустить на Mac
Как в `RELEASE_0.0.2.md` (Godot 4.7.2, двойной клик по `play-mac.command`):
```bash
git clone https://github.com/elv1bro/nullcub.git && cd nullcub     # или: git checkout main && git pull
./play-mac.command                # или play-latest.command: подтянуть main и запустить
```
Скрипт сам делает `--import` после смены версии кода (в этой сборке новые модели деталей и спорт-зала — первый запуск дольше).

## Что нового с 0.0.2
- **Наборы деталей 04.10** (`KIT_SETS.md`, коммит `bd9fc75`). 37 новых деталей кита по трём листам автора (скрипты Blender): про-лига Земли, живые детали Аоэлюн и разветвители — тройник, узел-сплетение, рама-позвонок, позвонок; в ките теперь 151 деталь. Девять шаблонов мастерской: Спринтер, Титан, Хищник и Таран Аоэлюн, Сороконожка, Мультитул, Левиафан Аоэлюн, Химера и заготовка «Открытая категория» с бюджетом 300.
- **Броня** (`ARMOR_BREAK.md`). Щиток снимает долю урона с ударов в своё тело, у тяжёлых ядер своя броня. Поломка деталей по материалу (`Tuning.PART_BREAK`) сделана, но **выключена**.
- **Прочность суставов** — пробный режим, **клавиша C в бою, по умолчанию выключен** (`JOINT_BREAK.md`, `1b43adf`). Суставы изнашиваются от ударов, конечности отлетают; чем дальше сустав от ядра, тем меньше запас (32 → 22.4 → 15.7, не ниже 8). Работает на обычной кукле и на бойцах из деталей; повреждённый сустав искрит, при отрыве — вспышка.
- **Спорт-зал** — пробный режим во «ВСЕ РЕЖИМЫ» (`SPORT.md`). Футбол, баскетбол и волейбол до 3 голов в зале из кита Old NULL Hall. Мяч бьют телом, за P2 играет бот (U — отдать P2 человеку, F — сменить вид спорта), нокаут не кончает матч — кукла возвращается через 2,5 с.
- **Руины.** Ямы у краёв закрыты стенками под землёй: кукла больше не уходит под пол и не прячется там до конца боя. Проба матча на Руинах снова стабильна (раньше часть боёв шла без KO: 2 из 6 прогонов пробы, 2 из 21).
- **Мастерская.** У активных блоков «по нажатию» (минный лоток, пружина-катапульта) в паспорте детали появилось описание с ценой («тратит 25 заряда за раз»): раньше была ошибка скрипта и пустая строка. У крюка-кошки показаны обе цены — за нажатие и за секунду тяги.
- **Инструменты.** Сборщик кита (`tools/build_body_kit.gd`) больше не портит сцены пресетов: сцена пишется текстом, без изменений не переписывается, а если скрипт куклы не компилируется в режиме `-s`, сборщик падает с ошибкой вместо записи мусора (`BODY_KIT.md` §3.5). Экспортёр каталога деталей (`tools/catalog_export.tscn` + `build_catalog.py`). Сама страница `docs/catalog/` в git не положена: 24 МБ, ≈ 2500 картинок, пересобирается.
- **Лор** (только документы): патчи `LORE_V2` 03–04.10 — пролог с братом-близнецом, слои Земля ↔ NULL, древняя история Устроителей (скрытый эксперимент, Aoëlun созданы ими); черновик физики мира `WORLD_BIBLE.md`.

## Известные проблемы
Старые пункты с шагами — `HOTFIX_2026-10-02.md` и раздел «Известные проблемы» в `RELEASE_0.0.2.md` (длинные языки, первый вход в мастерскую, английское название сборки в чертеже — не закрыты). Новое:
- `hitfx_core_probe` нестабильна сама по себе: на чистом `8a7c23f` 1 прогон из 17 красный (`freq_crit_power_lost`), с фиксом Руин 3 из 47 (`freq_normal_flight` 4.5–4.7); ещё 2 из 47 — SCRIPT ERROR в `hit_tier.gd:77`, при этом проба пропускает 13 проверок и выходит с кодом 0. Связь с правками не найдена; `run_hitfx_gate` может покраснеть — сверять с чистым main.
- Мастерская: подсказка кнопок канала в паспорте («Канал %d: пока зажата …», `workshop_ui.gd`) для мины и пружины неточна — они срабатывают по нажатию (P3).
- Суставы: реплика N0 на отрыв прежняя («Кто-то захочет это вернуть»), хотя в этом режиме деталь не возвращается. Вместе с ДРАЙВОМ (J) не проверено.
- Новые бойцы наборов проверены только покоем и движением под вводом; боя на них и сборки мышью в мастерской не было. Бюджеты шаблонов выше 100 (Титан 109, Сороконожка 179, Левиафан 214…) — сборщик поднял их сам.
- Спорт-зал: N0 голы не комментирует, толпы нет, площадка только на двоих (2×2 нет), пункта в главном меню гаража нет. В headless `sport_probe` печатает «Parameter "material" is null» — артефакт заглушки рендера, в окне его нет.
- Боты самой игры (EnemyBrain, RivalBrain) в ловушках Руин (помост над куклой, ящики под помостом) не проверены — фикс обхода касается только бота пробы.
- `build_body_kit.gd` печатает 6 ложных предупреждений «роль материала League_* из каталога без .tres» (P3).

## Решения автора (не блокируют)
- **Поломка тела:** какой счёт оставить — по материалу детали (`PART_BREAK`), по глубине сустава (клавиша C) или объединить. Для суставов: блок кистью режет HP, но не износ запястья; голова и ядро не отлетают; отлетевшая деталь до конца раунда не возвращается; частота ≈ 1 деталь за бой; читается ли износ без полосок и цифр (только искры и вспышка). Константы `JOINT_*` — в конце `tuning.gd`.
- **Броня и бюджет:** числа `Tuning.PART_ARMOR` стартовые; регламент бюджета для про-лиги, Аоэлюн и больших сборок.
- **Спорт-зал:** весело ли руками; футбол у ботов быстрый (5 голов за 35 с — меньше ворота или тяжелее мяч?), баскетбол долгий (2–3 минуты); нужен ли пункт в главном меню гаража.
- **Мастерская:** формулировки новых строк («Срабатывает по нажатию клавиши канала; тратит %s.», «%.0f заряда за раз», «%.0f заряда за нажатие и %.0f заряда/с»).
- **Каталог:** класть ли сгенерированную страницу `docs/catalog/` в git.
- **Лор:** роль Основателя, значение ELIGIBLE, ограничения NULL-волн.
- Не решено с 0.0.2: скин HUD (или оставить переключатель H), OFL-шрифт с кириллицей, что из ДРАЙВА включить по умолчанию, вариант замедления на 0, микс звука, проверка названия NULL GRAVITY на занятость.
