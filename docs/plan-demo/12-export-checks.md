# 12 — Экспорт и чек-лист демо

Вход: всё готово. Выход: сборки для показа и подтверждённый чек-лист.

## Экспорт

- Пресеты: Windows x86_64, macOS universal (подпись пока ad-hoc), Linux x86_64. Веб не делаем в демо.
- Иконка, имя «Ragdoll Master Demo», версия из `project.godot`.
- Размер сборки записать; цель меньше 200 МБ.

## Чек-лист (каждый пункт руками)

- [ ] Запуск без терминала на Mac и Windows
- [ ] Меню → 4 участника (2 человека + 2 бота) → матч → итоги → Play again → меню, дважды
- [ ] 60 FPS на среднем ноутбуке при 4 куклах, 5 предметах, 30 обломках
- [ ] Ни одна кукла не проваливается сквозь пол за 10 матчей
- [ ] Ни одной «взрывающейся» куклы при спавне
- [ ] Лица на головах у всех 4, фото загружаются
- [ ] KO-замедление и лучшие моменты показываются после каждого матча
- [ ] Сохранённый повтор открывается после перезапуска игры
- [ ] Звук: удары, KO, музыка меню и боя
- [ ] Esc из любого экрана ведёт назад
