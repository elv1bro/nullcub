# 18 — Первое вторжение: финал демо

Вход:
- этап 13: мембрана, шейдер прогиба;
- этап 14: N0 и табло;
- этап 15: точка входа аномалии;
- этап 17: финал местной лиги;
- PvE: `scripts/pve/wave_director.gd`, `scenes/playground_pve.tscn`, строки поля из PR #1;
- детали NULL League (`tools/blender/kit_league.py`, ветка этапа 13);
- лор §14–15.

Выход: финальный бой местной лиги прерывает вторжение.
- Мембрана прогибается внутрь без касания, табло пишет MEMBRANE BREACH.
- Сквозь мембрану входят чужаки, соперник по финалу становится союзником.
- 2–3 волны, итог и крючок на тайну N0. На этом демо заканчивается.

## Сцена по шагам (предложение)

1. **Финал идёт как обычный бой.** Примерно на 60-й секунде, или когда у соперника остаётся меньше 30 % HP, мембрана прогибается внутрь в одной точке: это шейдер прогиба с обратным знаком (§14). Толпа думает, что это шоу, и радуется. N0: «Это часть программы?.. Нет?»
2. **MEMBRANE BREACH.** Табло обрывает бой. Соперник переходит в команду игрока: урон между ними выключается через `team`.
3. **Чужаки.** Это `ModularDoll`, собранные «по совсем другим принципам» (§15): асимметрия, детали NULL League, свой цвет.
   - Их 2–3 волны через `WaveDirector`.
   - Строки INCURSION N и BREACH SEALED — предложение из `N0_VOICE.md`.
   - Кто эти чужаки на самом деле, демо не раскрывает: на табло просто UNKNOWN ENTITY. Идея «беглецы из захваченных миров» — пока предложение (`LORE_NULL.md`, п. 4).
4. **Конец.**
   - Табло: BREACH SEALED.
   - N0: «Этого… нет в моём расписании».
   - На секунду экран N0 переходит в GLITCH и показывает строку MEMORY RESET · CYCLE 217 (§9).
   - Надпись «Продолжение следует», затем меню.

## Проверка

- Проба: финал разыгрывают боты.
  - Прогиб мембраны наступает.
  - После BREACH команды переключаются, урон между игроком и союзником равен 0.
  - Все волны проходят, показывается финальный экран.
- Три прогона подряд без зависаний.
- Снимки четырёх ключевых кадров: прогиб, BREACH, волна с союзником, GLITCH N0.
