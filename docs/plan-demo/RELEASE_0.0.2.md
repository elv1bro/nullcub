# NULL GRAVITY — тестовая сборка 0.0.2 (02–03.10.2026)

Вторая общая сборка: в `main` слита работа всех параллельных сессий после 0.0.1. Живёт в ветке **`main`** (тег `v0.0.2`), а не в отдельной ветке, как 0.0.1. Это по-прежнему не готовое демо, а сборка для тестирования автором.

## Как запустить на Mac
Как в `RELEASE_0.0.1.md` (Godot 4.7.2, двойной клик по `play-mac.command`), но код теперь в `main`:
```bash
git clone https://github.com/elv1bro/nullcub.git && cd nullcub     # или: git checkout main && git pull
./play-mac.command                # или play-latest.command: подтянуть main и запустить
```
Скрипт сам делает `--import` после смены версии кода. Главная сцена теперь **`scenes/boot.tscn`** (лоадер): любая смена сцены идёт через `Loading.change_scene` и асинхронна — свои пробы, ждущие смену сцены, должны ждать `Loading.showing == false`.

## Что нового с 0.0.1
- **Название и знак.** Игра называется **NULL GRAVITY** (название чужой «Ragdoll Master(s)» убрано везде, `BRAND.md`); знак и иконка — дрон N0 (`assets/ui/brand/`).
- **Языки.** Русский и английский, строка «ЯЗЫК» первой в НАСТРОЙКАХ гаража; новый язык — один файл `godot/locale/<код>.json` (`python3 godot/tools/i18n.py new <код> <Название>`). Все видимые подписи через `tr()`. Проверки: `i18n.py check`, `i18n_probe`, `i18n_scenes_probe`, `i18n_layout_probe` (вёрстка на всех языках и на псевдоязыке `qps`), `tools/i18n_shots.sh <язык>`. Подробно — `I18N.md`.
- **Гараж.** Кампания «История» идёт прямо в эфире телевизора гаража (без смены сцены), мастерская внутри гаража и тренировочный зал за её воротами, экран «Трофеи», кукла игрока в гараже, живой эфир ботов на ТВ; экран ТВ рисуется в 1.5× (текст читается). Настройки: язык, громкость, графика, **авто-масштаб** 3D, эффекты ударов, интерфейс боя (3 скина HUD: трансляция / неон / LED, клавиша H), полный экран, V-Sync, субтитры.
- **Бой.** Новая схема управления: варианты тяги (тело / голова / голова+стойка / таран…), темп, панель Tab с ползунками, клавиши V/T (`CONTROL_FEEL.md`); **ДРАЙВ** (клавиша J, по умолчанию выключен: «импульс живёт», `DRIVE.md`); «сок удара» на языке игры (обломки по материалу, сколы, цифры-обломки, серьёзный стиль удара, 4 варианта замедления на 0, панель клавиш L, масштаб камеры колесом, обводка B); камера купола за игроком, масштаб боя по умолчанию 1.5×; N0 летит рядом, стрелка с метрами до соперника.
- **Звук.** Переработан целиком: удары, толпа, стук столкновений, фон арен, музыка (M/N) — `AUDIO.md`.
- **Производительность.** Авто-масштаб 3D и пресет по видеокарте при первом запуске, VRAM-сжатие и усечение текстур, интерполяция физики, кэши PvE/куклы, быстрый вход в мастерскую (≈ 90 мс) и «Испытать», лоадер — `PERF_PASS.md` §10–11.
- **Лор.** Единый канон «НЕ ОДНИ» (`LORE_V2.md`, `new_book_loor.md`): NULL — четвёртое измерение, Основатель, Земля за кадром.
- **Инструменты.** `godot_nofocus.sh` (оконные пробы без кражи фокуса), гейт производительности `run_perf_gate.sh`, `tools/i18n.py`; правила для всех агентов в `AGENTS.md`.

## Проверено (03.10.2026, `main` 9f943ae + версия, чистый worktree)
- `python3 godot/tools/i18n.py check`: 0 ошибок (1487 ключей, 14 предупреждений о длине английского).
- Все headless-пробы `tests/*_probe.tscn` (кроме перформанс-замеров и оконных): **55 зелёных** + гейты `run_gate`, `run_combat_gate`, `run_audio_gate`, `run_hitfx_gate` — все зелёные.
- Красные: `scrap_machines_probe` (`magnet_iron_part`: сила на железные части 0 — красный и в сборке 0.0.1, старый дефект магнита Свалки); `fx_probe` — оконная проба-снимок, в headless не завершается (не дефект). Пробы производительности (`perf_probe`, `perf_gate_probe`, `pve_cpu_probe`, `light_cost_probe`, `gfx_probe`, `dynres_probe`, `scrap_perf_probe`, холодный старт) не гонялись: замеры времени под нагрузкой врут, их прогоняла сессия FPS (все зелёные на 9f943ae).

## Известные проблемы (подробно с шагами — `HOTFIX_2026-10-02.md`)
- Длинные языки: реплика N0 вылезает из плашки и налезает на подсказки (гараж, ТВ кампании), описания пунктов гаража, название кубка на стрелках, подсказка клавиш в куполе шире окна (проба `i18n_layout_probe -- "langs=qps"`).
- Мастерская: звук щелчка кнопки и «дерево» (`ws_sfx_probe` после возврата сэмплов снова 50/50 — пункты H1/H2 хотфикса закрыты `05a0458`), первый вход в мастерскую (250–450 мс) и первое «Испытать» подвисают из-за сборки пайплайнов Metal.
- Управление: `control_feel_probe` — `responds_rotate` красный для варианта «РУЛЬ» (порог пробы или вариант).
- Английское название сборки записывается в чертёж и не возвращается на русский (H4).
- Не сделано: толпа/трибуны и звук ворот в тренировочном зале, голос N0, петля звука ускорения, коллайдеры гаражных пропсов.
