# Замена болванок на настоящие модели героев

Физический риг (`godot/scenes/doll/doll.gd`) не зависит от внешнего вида: 14 `RigidBody3D` с именами `Head, Torso, UpperArm_L/R, LowerArm_L/R, Hand_L/R, UpperLeg_L/R, LowerLeg_L/R, Foot_L/R`. Внешняя модель надевается на него адаптером `godot/scenes/doll/doll_skin.gd`. Поддерживаются два варианта модели. Эталон внешнего вида — `docs/refs/R14-a-character-base.jpg`.

**Модульность (кастом и прокачка):** так как каждая часть — отдельный меш с именем, части можно подменять по одной (другая голова, руки, ноги, торс) без изменения рига: набор частей = «скин», отдельная часть = «деталь». Каталог деталей планируется как `heroes/<набор>/<часть>.glb`; адаптер берёт часть из набора, а если её нет — из базового манекена.

## Вариант A — модель из отдельных частей (проще, рекомендуется)

Файл `.glb` (или `.gltf`), внутри 14 мешей с именами частей выше (регистр важен; допускается суффикс, например `Head_mesh`; кисти можно опустить, тогда останутся болванки). Дополнительные меши (шляпа, лицо) вешаются дочерними к своей части: `FacePlate` под `Head`.

Требования:
- Метры, Y вверх, персонаж **смотрит в камеру, то есть в +Z**; X — вбок (плечи на x = ±0.22, бёдра ±0.10), стоит на y = 0, рост около **1.8 м** (голова 0.24×0.30). Если масштаб другой, адаптер подгонит по росту (`auto_scale = true`), но пропорции должны быть близки к R22 (риг v3: шея 1.47, плечи 1.43, локти 1.13, запястья 0.86, бёдра 0.91, колени 0.49, лодыжки 0.09).
- Поза покоя: стоя лицом к камере, руки вдоль тела по бокам (как в `assets/models/heroes/mannequin/mannequin.glb`).
- Origin каждой части не важен: адаптер сам считает смещение части относительно тела в позе покоя.

Как подключить: положить файл в `godot/assets/models/heroes/<имя>.glb`, в `Doll` выставить `skin_scene = "res://assets/models/heroes/<имя>.glb"`, `skin_mode = "parts"`. Проверка: `godot --path godot --resolution 1280x720 res://tests/snapshot.tscn -- "skin=res://assets/models/heroes/<имя>.glb"`.

## Вариант B — один меш со скелетом (риггед-модель)

Файл `.glb` с `Skeleton3D`. Нужна таблица соответствия костей частям, например:

```
Head=head, Torso=spine, UpperArm_L=upperarm.L, LowerArm_L=lowerarm.L, ...
```

Адаптер каждый физический кадр ставит глобальную позу кости из трансформа соответствующего RigidBody (с учётом смещения покоя). Требования те же: метры, Y вверх, +X вперёд, T-поза или A-поза допустимы, но поза покоя рига (стоя, руки вниз) должна быть достижима без ломки костей. Кости сверх 12 (пальцы, шея-2) наследуют родителя.

Как подключить: `skin_mode = "skeleton"`, `skin_bone_map = "Head=head,Torso=spine,..."`.

## Что делать с лицом

В варианте A `FacePlate` — отдельный меш под `Head` с UV 0–1 под фото; в варианте B — отдельный меш, привязанный к кости головы. Материал `Face` адаптер находит по имени и подменяет текстуру на фото игрока (этап 10).

## Чек-лист приёмки модели

1. Импорт в Godot без предупреждений (`godot --headless --path godot --import`).
2. `tests/snapshot.tscn` со `skin=`: кукла стоит, части не «плывут» относительно физики, руки не внутри торса.
3. Гейт `tests/run_gate.sh` зелёный (модель не влияет на физику, но проверяем, что адаптер не роняет FPS).
