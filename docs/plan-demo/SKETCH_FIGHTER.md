# «Нарисуй» — боец из эскиза (прототип)

Игрок рисует мышью каракулю, игра собирает из неё бойца из деталей мастерской — и сразу в бой.
Вход — экран ВЫБОР БОЙЦА (`FIGHTER_SELECT.md`), раздел «МОЙ БОЕЦ»: карточка **«Нарисуй»** рядом с «Быстрой сборкой», клавиша **D**.
Холст открывается в том же экране (как «Быстрая сборка»), превью бойца справа — тот же портрет и строка «масса · энергия · детали».
Последний эскиз сессии остаётся карточкой **«Прошлый эскиз»** (`FighterPick.sketch`); D или клик по «Нарисуй» открывает холст с ним.
Выбор уходит в бой тем же путём, что весь экран: `chosen` → `ModeRun.launch(def, {player_blueprint: bp})`.

Снимки (1920×1080, поверх гаража) — `docs/plan-demo/sketch_fighter/`:

| | RU | EN |
|---|---|---|
| человечек: круг, голова, 2 руки, 2 ноги — превью справа | `ru_human.png` | `en_human.png` |
| многорукий: 3 руки с каждой стороны, без ног | `ru_multi.png` | `en_multi.png` |
| человечек + зигзаг на конце руки — навершие (ЛКМ на нём) | `ru_hammer.png` | `en_hammer.png` |

Переснять: `GODOT_BIN=/usr/local/bin/godot godot/tools/godot_bg.sh --path godot --resolution 1920x1080 --fixed-fps 60 res://tests/sketch_snapshot.tscn -- out_dir=<абсолютный путь>`

## Клавиши холста

| Клавиша | Что делает |
|---|---|
| ЛКМ (тянуть) | штрих |
| ПКМ или Backspace | отменить последний штрих |
| C | очистить холст |
| S | симметрия вкл/выкл (по умолчанию **вкл**: штрих с одной стороны оси повторяется на другой; на оси или уже зеркальный — не повторяется) |
| N | ещё вариант деталей (тот же рисунок, другой seed) |
| Enter | в бой с этим бойцом |
| M | в мастерскую с этим бойцом (`FighterPick.open_workshop`) |
| Esc | к карточкам (эскиз остаётся «Прошлым эскизом») |

Превью пересобирается через 0,35 с после последнего штриха (`SKETCH_DEBOUNCE`), Enter пересобирает сразу, если не успело.
Штрихи на холсте раскрашены по роли, которую им дал распознаватель (ядро, голова, конечность, звено, конец, декор, отброшено) —
видно, как игра поняла рисунок. Справа — «КАК РИСОВАТЬ» (9 правил) и строка распознавания: «Средний · рук 2 · ног 2 · кулак».

## Распознавание (`scripts/body/sketch_build.gd`, `SketchBuild`)

Без UI: на вход — штрихи (`PackedVector2Array`, координаты холста 760×640, y вниз) и seed; на выход — словарь как у
`QuickBuild.generate` (`bp`, `strike`, …) плюс `info` (роль каждого штриха, конечности, рук/ног, строка).
Все размеры — относительно ядра, поэтому масштаб рисунка не важен.

| Рисунок | Деталь |
|---|---|
| самый крупный замкнутый штрих | ядро. Радиус (доля меньшей стороны холста): < 0,105 — **Быстрый**, > 0,165 — **Тяжёлый**, между — **Средний**. Вытянутое — высокое ядро (бочка, котёл, игрушка, торс), круглое — барабан, клетка, реактор, ящик |
| меньший замкнутый штрих над ядром | голова (крупная, от половины ядра, — голова-таран); не нарисована — голова по умолчанию |
| открытый штрих от края ядра | конечность: старт сверху-сбоку — плечо, середина бока — бок, снизу — бедро (штрих вниз — нога). Правая половина экрана — якоря `*_L` (портрет смотрит в −z). Длина в диаметрах ядра → 1 или 2 звена, S или L |
| волна от ядра | щупальце |
| зигзаг на конце руки (в том же штрихе или отдельным штрихом у конца) | навершие-оружие (молот, топор…) — ЛКМ на нём |
| петля / кружок на конце | булава |
| волна от конца руки | кистень: цепь + булава |
| короткий прямой штрих у кисти | кулак |
| длинный прямой штрих от конца | ещё звено (до 3) |
| штрих вверх от головы или верха ядра | рога / антенна |

Лишние руки встают на свободные якоря (бок, бедро); не влезло или не понято — штрих «отброшен» (бледно-серый на холсте).
ЛКМ (`strike`) — на ударной детали: первая рука с нарисованным концом (навершие / булава / кистень), иначе первой руке ставится кулак и ЛКМ на нём; рук нет — конец ноги, затем голова.

**Всегда валидный боец.** Сборка — только через API мастерской (`CraftEdit.set_root`, `check` + `_apply_attach`, `set_control`)
и помощники `QuickBuild`, поэтому чертёж проходит те же проверки: якоря, вид детали, энергия (`energy_cap` — и с «запасом из деталей», и без).
Не влезло в энергию — уступки по уровням, как у QuickBuild: лёгкие пулы и цепь в одно звено → тонкие звенья и простые кисти →
по одному звену и не больше 4 конечностей; последний запас — `QuickBuild` по умолчанию (`info.fallback`).
Пустой рисунок и рисунок без конечностей — человечек «Средний» (обычные 2 руки и 2 ноги).
Тот же рисунок и seed → тот же чертёж (детерминизм), N меняет seed.

## Ограничения прототипа

- Распознаются только простые формы (круг, линия, зигзаг, волна, петля); сложный рисунок (лицо, детали внутри тела, штриховка) не разбирается — лишнее отбрасывается.
- Рисунок «боком» или ногами вверх читается как обычный: якорь выбирается по месту старта штриха на краю ядра.
- Без конечностей — обычные 2 руки и 2 ноги; на одном круге строка говорит «конечностей нет — поставлены обычные», на пустом холсте пометки нет.
- Каракуля без замкнутого штриха: ядро «Среднее» в середине рисунка, в пробе — одна рука с навершием и без ног; валидно, но на рисунок мало похоже.
- Многорукий без нарисованных ног остаётся без ног (так задумано: рисунок важнее), такой боец ползает.
- Эскиз живёт только в сессии (`FighterPick.sketch`), на диск не сохраняется; сохранить — M → мастерская → «Сохранить».
- Распознавание и холст — только мышь; на геймпаде холст не работает (не проверено, что карточка не мешает геймпаду).
