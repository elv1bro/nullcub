# Ragdoll Master — тестовая сборка 0.0.1 (02.10.2026)

Первая общая сборка. В неё слита работа всех параллельных сессий на 02.10.2026. Это не готовое демо: сборка для того, чтобы автор поиграл во всё сделанное и сказал, что поправить. Номер версии — в `godot/project.godot` (`config/version="0.0.1"`). Код — тег `v0.0.1`.

## Как запустить на Mac

1. **Godot 4.7.2.** Скачать для macOS: https://godotengine.org/download/macos/. Если на сайте уже версия новее, взять 4.7.2-stable из архива: https://godotengine.org/download/archive/. Распаковать и положить `Godot.app` в «Программы».
2. **Код сборки.** В Терминале:
   ```bash
   git clone https://github.com/elv1bro/nullcub.git
   cd nullcub
   git checkout v0.0.1
   ```
   Если репозиторий уже скачан: `git fetch origin --tags && git checkout v0.0.1`.
3. **Запуск.** Двойной клик по `play-mac.command` в корне репозитория (или `./play-mac.command` в Терминале).
   - Первый запуск дольше: Godot несколько минут импортирует модели и текстуры, потом окно игры откроется само.
   - macOS пишет «неизвестный разработчик» про `.command`: правый клик → «Открыть». Или в Терминале: `chmod +x play-mac.command && ./play-mac.command`.
   - macOS не даёт открыть `Godot.app`: `xattr -dr com.apple.quarantine /Applications/Godot.app`.
   - Без скрипта: открыть Godot → «Импорт» → `nullcub/godot/project.godot` → «Импортировать и редактировать» → F5.

Игра открывается тестовым меню. Из любого режима **Esc** возвращает в меню. Исключение — мастерская: там двойной Esc закрывает игру.

## Управление

- **P1:** WASD — летать, Shift — рывок, Space — переворот; мышь: ЛКМ / ПКМ — тяги рук; I / O / P — активные блоки.
- **P2:** стрелки, правый Ctrl — рывок, Enter — переворот; Num 1 / 2 / 3 — активные блоки.
- **Общее:** R — бой заново, 1–9 — сменить площадку, F10 — эффекты ударов full / reduced / off, Esc — в меню.
- **Выход бойца в кампании:** любая клавиша — быстрее, дважды — пропустить.

## Что проверить руками

1. **Кампания** целиком: 4 боя, трофей после каждой победы, поражение — переигровка, мастерская только со стартовыми деталями и трофеями, перерасход энергии (тело + оружие) не пускает в бой.
2. **Выход бойца:** понятно ли, что за мембраной начинается поле NULL; не слишком ли долго (около 10 с на двоих).
3. **Голосование:** читается ли панель, мешает ли бою; аномалия в 3-м бою — заметна ли.
4. **Купол в Быстром бою:** отскок от мембраны как приём, смена поля клавишей G.
5. **Мастерская:** удобство, активные блоки в бою.
6. **Feel** боя на всех аренах.

## Известные проблемы

- N0 говорит только субтитрами-заглушками (кампания, голосование), голоса нет — этап 14.
- Финал кампании — экран «Продолжение следует». Вторжения ещё нет — этап 18.
- Нет главного меню (это тестовое), лица игрока (этап 10), повтора и итогов (09), готовой программы (.app, этап 12).
- В Быстром бою нет выхода бойца, только в кампании.
- Мастерская: кнопка «В руку» при перерасходе энергии не отказывает сразу — отказывают «Испытать» и бой.
- Бой двух ботов на «Руинах» (`match_probe`) иногда не доходит до нокаута за 120 с (1 прогон из 3) — разброс ботов, не игрока.
- Производительность на Mac в этой сборке не мерили.
