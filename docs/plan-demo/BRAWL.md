# Стенка на стенку 5×5 (10.10.2026)

Автор 08.10: «5×5 это другой режим» (MODES_IDEAS.md, Б1). Режим без лора, как стычка и бомба. Две команды по пять кукол на Полигоне,
без оружия, классов и ящиков — только тело. Последняя живая команда берёт раунд, матч — до 2 побед.

## Как запустить

- В игре: гараж → **ВСЕ РЕЖИМЫ** → «Стенка на стенку 5×5» (после строк гонки, перед «Арена «Руины»»).
- Напрямую: `godot --path godot res://scenes/playground_brawl.tscn`.

## Правила

- **Команды:** синие — P1 (человек) и боты P3, P5, P7, P9 (чётный `player_index`), слева; красные — P2 и боты P4, P6, P8, P10,
  справа (точки `BRAWL_SPAWN`, у красных зеркально по x). У всех тело «Человек» (kit_human), рубашка и обводка — цвет команды.
- **Свои не ранят:** `Doll.team = "brawl_0" / "brawl_1"`, `team_damage_mult = 0` — удар своего не снимает запас и не оглушает, толчок
  полный (как в стычке). Чужие бьют как в обычном бою (DollCombat, запас из деталей).
- **Раунд:** выбывший не возвращается до конца раунда. У команды не осталось живых — раунд другой (обе выбыли в одном тике — ничья,
  раунд никому). Пропасть Полигона — KO.
- **Лимит раунда 120 с** (`BRAWL_ROUND_LIMIT_S`): дальше Sudden Death как в Match (отброс растёт шагом `SUDDEN_DEATH_STEP_S`). На
  **180 с** (`BRAWL_ROUND_HARD_S`) раунд — команде с большим суммарным запасом живых (равно — ничья).
- **Между раундами** пауза 3 с, затем все десять заново на своих точках (новые куклы, SD сброшен), отсчёт 2 с.
- **Матч до 2 побед** (`BRAWL_WINS_TO_WIN`), затем итоги: «ПОБЕДА СИНИХ / КРАСНЫХ», счёт раундов, таблица бойцов (нокауты, выбывания,
  урон за весь матч), медали Match за весь матч. **R** — заново.
- Эффекты удара и KO (тряска, стоп-кадр, замедление 0.4 с, надписи) — только с участием человека: драка ботов на другом краю не дёргает
  кадр. Крит-кино выключено.

## Управление

| Клавиша | Что |
|---|---|
| WASD, Shift, Space + A/D, ЛКМ | P1 (синие): полёт, ускорение, раскрутка, рука к курсору |
| стрелки, правый Ctrl, Enter | P2 (красные), если он человек (или второй просто жмёт стрелку — бот отдаёт управление сам) |
| U | P2: бот ↔ человек |
| K | уровень ботов 1 → 2 → 3 |
| R | матч заново |
| Esc | пауза (продолжить / заново / в гараж) |
| M / N / H | музыка / толпа / скин HUD |
| 1–9 | площадки хаба |

Камера (`DynamicCamera`, группа `brawl_focus`) держит живых людей и до 2 ближайших к ним живых врагов не дальше 12 м
(`BRAWL_FOCUS_N`, `BRAWL_FOCUS_M`); людей не осталось — всех живых.

## HUD

Сверху «РАУНД N · ДО 2 ПОБЕД», счёт раундов «1 : 0» и таймер раунда (в Sudden Death — красный остаток до решения по запасу, между
раундами — «ПАУЗА»). По бокам — плашки СИНИЕ / КРАСНЫЕ с пятью кружками живых (выбывший — пустой). Над куклами — имя цветом команды
(«ТЫ» у P1-человека) и полоска запаса. Диктор: отсчёт, FIGHT!, KO!, SUDDEN DEATH, «СИНИЕ БЕРУТ РАУНД». Снизу подсказка клавиш (гаснет
через 14 с). В конце — табличка итогов.

## Боты (BrawlBrain)

Каркас `EnemyBrain` (тяга с плавным разворотом, восприятие с задержкой и упреждением, выход из застревания). Цель — ближайший живой
враг (у врагов остался один — он ближайший всем, все идут на него). Наскок → отход `retreat_s` → снова наскок; дальше 2 м — рывок
(уровни 2–3). Держится своих: дальше 9 м от центра живых своих (`BRAWL_BOT_COHESION_M`) к тяге на цель примешивается тяга к ним (на
18 м — целиком). Разнос `EnemyBrain.separation` по группе своей команды — не толпятся. Вне раунда (отсчёт, пауза, итоги) висят.
Уровни 1–3 — `BRAWL_BOT_LEVELS` (доля тяги, реакция, ошибка прицела, упреждение, отход, рывок).

## Устройство

| Что | Где |
|---|---|
| Матч: команды, раунды, лимит и SD, решение по запасу, журналы, итоги | `godot/scripts/brawl/brawl_match.gd` (`BrawlMatch extends Match`) |
| Бот | `godot/scripts/brawl/brawl_brain.gd` (`BrawlBrain extends EnemyBrain`) |
| Площадка: десять кукол, U / K / R, камера | `godot/scenes/brawl/playground_brawl.gd`, сцена `godot/scenes/playground_brawl.tscn` |
| HUD | `godot/scenes/brawl/brawl_hud.gd` (`BrawlHud`) |
| Числа | `godot/scripts/tuning.gd`, блок «СТЕНКА НА СТЕНКУ 5×5» в конце: `BRAWL_*` |
| Проба | `godot/tests/brawl_probe.gd` + `.tscn` |

`match.gd`, `doll.gd`, `doll_combat.gd` не правились: всё — переопределения в `BrawlMatch` (`register`, `_start_fight`,
`_physics_process`, `_on_doll_ko`, `on_hit`, `_check_over`, `_finish`, `build_results`, `spawn_point_for`). Часы Match (`time_limit_s`)
выключены, лимит считает `round_time` раунда.

## Проверки

```bash
godot --headless --path godot --fixed-fps 60 res://tests/brawl_probe.tscn                       # rules + bots
godot --headless --path godot --fixed-fps 60 res://tests/brawl_probe.tscn -- "only=bots,level=3,trace=1"
```

Секции: **rules** (мозги выключены, куклы ставит проба) — десять кукол, по пять в командах, стороны, свой бьёт своего — урон 0 и отброс
есть, чужого — урон есть; выбывший не возвращается; последняя живая команда берёт раунд; пауза 3 с и все на точках; 120 с → SD, шаги
отброса; 180 с → раунд по запасу; третий раунд с чистого листа; матч до 2 → итоги, медали, табличка HUD; R — сброс. **bots** — матч
десяти ботов доигрывается, раунды решены, своих не выбивают, никто не застрял, все в границах, `info.phys_ms` — среднее время
физического тика. Обе секции: ошибок скриптов и движка — 0.

## Не сделано / ждёт автора

- **Перф:** 10 кукол — физика ≈ 10–12 мс / тик в headless-контейнере (порог-предупреждение пробы 6 мс; проба не валит). На машине
  автора не мерено; если в окне тормозит — меньше деталей у «Человека» или 4×4.
- В реестр «РЕЖИМЫ: 100+ вариантов» (modes_menu, площадка × модификаторы) не добавлен — только пункт в «ВСЕ РЕЖИМЫ».
- P2 — человек только на клавиатуре (стрелки); геймпадов и онлайна нет.
- Снимков (`img/brawl/`) нет — оконные пробы не гонялись.
- Пятый и десятый игрок-человек не предусмотрены: людей максимум двое (P1 синие, P2 красные).
