# 08 — Локальные игроки и боты

Вход: бой (06). Выход: матч на 2–4 участников, любая комбинация людей и ботов.

## Ввод

- До 4 участников. Слоты P1–P4, цвет рубашки синий/красный/зелёный/жёлтый.
- P1 клавиатура WASD + Shift рывок + Space переворот; P2 стрелки + правый Ctrl + правый Shift; P3, P4 только геймпады. Любой геймпад может занять любой слот нажатием Start в лобби.
- Схемы в `scripts/input/player_input.gd`, читаются через InputMap из этапа 03.
- Тач-стик не делаем в демо (десктоп-only), оставить заглушку.

## Боты

- Перенос логики из TS `src/battle/aiLogic.ts`: состояния approach / lunge / strafe / retreat, цель ближайший живой, рывок при дистанции 1–2 м, отход при HP ниже 30 %.
- Три уровня: easy (сила ×0.7, реакция 0.4 с), normal (×1.0, 0.25 с), hard (×1.15, 0.15 с, использует оружие).
- Бот управляет той же куклой теми же силами, никаких читов физики.

## Матч на 4

- Каждый сам за себя; победитель последний живой; при тайм-ауте больший HP.
- Камера следит за всеми живыми, зум по разбросу.

## Проверка

Лестница ботов: hard побеждает easy не реже 7 из 10; средний бой 4 ботов 20–60 с. Четыре человека с двумя геймпадами стартуют матч из лобби без правок кода.

## Из CONCEPT.md (27.09.2026)

Дополняет ввод и ботов выше. Сверка — `CONCEPT_GAP.md` (§3, §21, §27 MVP2).

- **Стик задаёт направление и силу (§3):** `Input.get_vector` с `limit_length(1)` — модуль вектора = доля силы (уже в `doll.gd`), мёртвая зона 0.25 (InputMap). Клавиатура — всегда полная сила.
- **Кнопки по концепту:** «дополнительный импульс» = рывок (`dash`: Shift / правый Ctrl / пад A), «специальное действие» = переворот (`flip`: Space / Enter / пад B), «отпустить предмет» = `drop` (Q / правый Shift / пад X; добавить в `input_setup.gd`), «захват» — автоматический (07), «взаимодействие с объектами» — не в демо. Start на паде = занять слот в лобби / пауза. Управления отдельными руками и ногами нет и не будет.
- **P3/P4 только пады; пады 0–1 дублируют P1/P2** — как в `input_setup.gd`; 1 человек = 1 + боты (концепт «1–4 игрока»).
- **Боты (концепт их не описывает, оставляем):** к состояниям approach / lunge / strafe / retreat добавить **whip** — ключевой приём §4/§25: на дистанции 1.2–1.8 м бот резко меняет направление на 0.3 с, чтобы конечности или оружие догнали тело по дуге; после whip — lunge. В стане ввод бота = 0 (как у человека). Бот использует рывок для погони за улетающим. Никаких читов физики — те же силы, что у человека.
- **Матч на 4 (§21):** каждый за себя; места и tie-break на 180 с — по 06; камера по правилам 05 (AABB всех живых, максимум = арена). Массовые столкновения четырёх — норма, не баг: гейт «4 бота hard, 10 боёв, ни одного зависания физики (max скорость части < 40 м/с)».
- **Проверка (дополняет):** бой 2 ботов normal 30–90 с (по 06); бот с whip выигрывает у бота без whip ≥ 6 из 10 — иначе приём не работает и это сигнал про физику, не про AI.
