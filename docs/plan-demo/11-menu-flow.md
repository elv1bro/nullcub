# 11 — Меню и поток экранов

> **02.10.2026:** автор выбрал направление главного меню «Гараж + эфир»: слева тёмный гараж бойца с телевизором, по нему идёт трансляция NULL Fighting; справа — меню; камера переезжает по пунктам. Идея, болванка, кадры и промты для референсов — `MENU_GARAGE.md`. Правила навигации и проверки ниже остаются в силе.

Вход: всё игровое (05–10). Выход: путь от запуска до матча и обратно без застреваний.

## Экраны (по референсу)

1. **Главное меню**: Play, Characters, Settings, Replays, Stats (в демо только Play, Settings, Replays; остальные серые). Фон: кукла сидит на ящике и покачивается (физика включена, лёгкое дыхание силами).
2. **Choose your ragdoll**: 4 карточки P1–P4, у каждой фото/цвет, ряд шляп, кнопка Ready. Свободный слот занимается нажатием Start на геймпаде или клавиши. Пустые слоты можно заполнить ботами с выбором уровня.
3. **Match settings**: арена (одна, но селектор есть), лимит времени 60/90/120, sudden death вкл/выкл, жёсткий тайм-аут, предметы вкл/выкл, боты. Список участников с Ready. Кнопка Start match.
4. **Матч** (06–08) → KO → **Best moments** → **Results** (09) → Play again возвращает в Match settings с теми же участниками.
5. **Settings**: громкость музыки и эффектов, полноэкранный режим, переназначение клавиш P1/P2.
6. **Replays**: список сохранённых, открытие в плеере.

## Правила навигации

- Esc или B на геймпаде всегда шаг назад, из матча в паузу с «Выйти в меню».
- Ни один экран не ведёт в тупик; проверить путь Play → матч → Esc → Play дважды подряд.

## Стиль

По UI-борду R10: крупные надписи кистью, тёмные панели, акценты цветом игрока. Шрифты свободные (OFL).

## Проверка

Незнакомый человек без подсказок доходит до матча за 60 с и возвращается в меню.

- **Меню — последний приоритет (§29).** До этапа 11 главная сцена остаётся `playground`/арена с быстрым стартом; меню не должно задерживать MVP1–MVP2.
- **Настройки матча по концепту (§1, §12):** лимит времени 60/90/120 (по умолчанию 90), Sudden Death включён и начинается на лимите, hard timeout = лимит + 90 с (по умолчанию 180); эти три параметра показываются одной строкой «90 с → SD → 180 с». Предметы вкл/выкл — оружие R16. Карта: Castle/Руины единственная; селектор есть, остальные карты концепта (§22) не показывать.

- **Цикл «… → LAUGH → ещё раунд» (§26):** из итогов до следующего боя ≤ 2 нажатия и ≤ 5 с (Play again сразу стартует отсчёт с теми же участниками и картой). Это критерий приёмки наравне с «60 с до матча».
- **Управление меню:** клавиатура, любой геймпад (Steam-контроллеры — MVP6, не в демо); Esc / B назад — как выше.
- **Onboarding-минимум (MVP6, но дёшево):** в первом бою сессии одна подсказка на 8 с: «Разгонись и резко смени направление — конечности ударят сами». Больше туториала в демо нет.
- **Проверка (дополняет):** путь Play → матч → итоги → Play again → матч укладывается в 2 нажатия между боями; тумблер камеры с фото у 2 слотов и без у 2 — все 4 куклы стартуют с правильными лицами/цветами.
