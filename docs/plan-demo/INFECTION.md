# Заражение: коснулся — заразил (10.10.2026)

Идея — `MODES_IDEAS.md` Б5: «один заражённый (зелёный), коснулся — заразил, тот играет за заражённых; заражённые быстрее, но без рук».
Режим без лора, как бомба и стычка. Семеро в куполе Old NULL Hall, один заражён. Касание заражает. Дожил до конца партии — очко;
заразили всех — очко первому заражённому. Три партии, итоги по очкам.

## Как запустить

- В игре: гараж → **ВСЕ РЕЖИМЫ** → «Заражение: коснулся — заразил» (после «Стенка на стенку 5×5»).
- Напрямую: `godot --path godot res://scenes/playground_infection.tscn`.

## Правила

- **Семеро:** P1 (человек) + 6 ботов. P2 по умолчанию бот; **U** отдаёт его второму игроку на стрелках (или второй просто жмёт свою
  клавишу — бот отдаёт управление сам). Купол Old NULL Hall, гравитация обычная; смены поля (G), чемпиона (K арены) и голосования
  зрителей нет.
- **Первый заражённый** выбирается случайно в отсчёте партии, каждый раз не тот, что в прошлой партии. Заражённый — зелёный
  (`INFECTION_COLOR`), здоровые — каждый своим цветом (`INFECTION_COLORS`, семь цветов без зелёного).
- **Касание:** любая деталь заражённого касается любой детали живого здорового — тот заражён сразу: перекраска, зелёная вспышка с пылью,
  щелчок, тост диктора «ЗАРАЖЁН: P3». Удар не нужен. Только что заражённый сам заражает не раньше **0.5 с** (в куче заражение не
  прыгает по трём куклам за один тик).
- **Заражённые:** тяга ×1.15 и предел скорости ×1.15; руки мышью нет (ArmAssist снимается, что держал — роняет); рывка и раскрутки нет
  (Заряд обнулён и заперт каждый тик — `doll.gd` не правился).
- **Урона нет:** `Doll.incoming_mult = 0` у всех — удары только толкают (отброс полный), толчок видно вспышкой с пылью. Выпал из купола
  (`body_fell`) — выбыл до конца партии (страховка; в куполе не случается).
- **Партия 90 с.** Все заражены раньше — партия заражённым, очко **первому заражённому**. Время вышло — очко **каждому дожившему**
  здоровому. Последние **15 с** — пульс: контур мембраны зеленеет вспышкой, писк; пауза между ударами 1.0 → 0.25 с, к концу выше и
  громче; таймер HUD зелёный и пульсирует.
- **Матч — 3 партии.** Пауза 3 с, затем все снова здоровы на своих точках, новый первый заражённый, отсчёт 2 с. Итоги: места по очкам
  (равные очки — одно место), победитель — единственный лидер, иначе «НИЧЬЯ»; таблица: очки, заразил, дожил партий. **R** — заново.

## Управление

| Клавиша | Что |
|---|---|
| WASD, Shift, Space + A/D | P1: полёт, ускорение (за Заряд), раскрутка — пока здоров |
| мышь | P1: рука (ArmAssist) — пока здоров |
| стрелки, правый Ctrl, Enter | P2, если он человек |
| U | P2: бот ↔ человек |
| K | уровень ботов 1 → 2 → 3 |
| R | матч заново |
| Esc | пауза (продолжить / заново / в гараж) |
| M / N / H | музыка / толпа / скин HUD |
| 1–9 | площадки хаба |

## HUD и камера

- Сверху: «ПАРТИЯ N ИЗ 3», таймер партии, плашки семерых (цвет, ТЫ / ИГРОК / БОТ / ЗАРАЖЁН / ВЫБЫЛ, точки очков), под ними
  «ЗДОРОВЫХ: N · ЗАРАЖЁННЫХ: M». Над куклами — имена, над заражёнными — зелёное кольцо.
- Стрелка у края экрана к ближайшему «противнику» P1 за кадром: здоровому — к заражённому («ЗАРАЖЁН · P3 · 12 м», зелёная), заражённому —
  к здоровому («P3 · 12 м» его цветом).
- Камера держит людей и ближайшего к ним противника, если он ближе 14 м; людей нет — всех живых.
- Конец матча — табличка победителя и таблица бойцов.

## Боты (`InfectionBrain extends EnemyBrain`)

- **Заражённый** гонится за ближайшим здоровым с упреждением `lead_s`; цели у заражённых-ботов разные (чужую цель берёт, только если
  свободных нет).
- **Здоровый** убегает к точкам на кольце вдоль мембраны (эллипс мембраны, ужатый на 3 × 3.5 м, без углов у пола, плюс несколько точек
  внутри): дальше от заражённых, путь не мимо заражённого, не в кучу с другими здоровыми, случайная прибавка раз в 4 с. Заражённый
  ближе 4 м — паника вбок к середине купола с рывком; зажат у мембраны — рывок сквозь к середине с уклоном.
- Уровни 1–3 (`INFECTION_BOT_LEVELS`): доля тяги 0.8 / 0.92 / 1.0, ошибка прицела 0.6 / 0.35 / 0.2 м, реакция 0.35 / 0.25 / 0.15 с,
  упреждение 0.2 / 0.3 / 0.4 с, рывок у здоровых — со 2-го уровня.

Как сделано:
- Касание — опрос `get_colliding_bodies()` у всех деталей заражённых каждый тик (`contact_monitor` включается на всех деталях при
  регистрации), как в бомбе.
- Сигналы матча: `doll_infected(victim, by)` (by `null` — первый заражённый партии), `pulsed(urgency)`, `round_started`, `round_over`.
  Осталось партии — `round_left()` (у Match уже есть сигнал `time_left`).
- Рука P1-человека возвращается в новой партии: `respawn_doll` делает новую куклу, площадка ставит ArmAssist по `doll_replaced`.
- `match.gd`, `doll.gd`, `doll_combat.gd` не правились.

## Не сделано / ждёт автора

- **Баланс:** среди ботов заражённые всегда побеждают за 10–60 с (из 90), здоровые ни разу не дожили. Для человека, может, и нормально
  (бот-заражённых обходить можно), но крутить стоит: множитель скорости, пауза касания, длина партии — автору решить, что важнее.
- Снимков и клипа нет (только headless); пульс мембраны и вспышку заражения глазами не смотрели — не проверено.
- Свой звук заражения не делали — щелчок `stun` из SfxDirector, писк — синтез бомбы (`BombCarry.beep_stream`).
