# Заметки между диалогами

Правило: последний диалог дописывает сверху запись не длиннее 10 строк. Старые записи не удалять, но если их больше 10, самые нижние можно сжать в одну строку.

Формат записи:

```
## 2026-09-21 — этап NN
Сделано: ...
Не сошлось / открыто: ...
Следующему: с чего начать, что проверить первым делом
```
