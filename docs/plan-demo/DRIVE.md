# ДРАЙВ — пресет боя «импульс живёт» (02.10)

Статус: **реализовано 02.10, по умолчанию выключено, ждёт ручной оценки автора.** Клавиша **J** в любом бою (или кнопка
«ДРАЙВ» в панели Tab) включает и выключает всё сразу; состояние запоминается вместе с панелью управления. Выключен — игра
ровно как раньше (гейты и пробы те же).

Запрос автора 02.10: «мне всё равно не нравится, как идёт драка, нет драйва, как в тех играх, с которыми мы сравнивали; бой сухой.
Исследуй, с какими играми мы сравнивали, наш, и что не так. Ещё неплохая боевка была в JS-версии». После разбора — «делай, пробуй».

## 1. Разбор: почему бой сухой

С чем сравнивали: ролики Ragdoll Masters (2005) и Rubber Ninjas (2008) — `INSPIRATION_GAMES.md`, `FEEL_TARGET.md`, листы
`img/feel-compare-v7.png`, `img/ref-rubber-ninjas-motion.png` (самих роликов в Downloads больше нет); JS-версия — код `src/`
и клип `test-artifacts/ad-shorts`; наш бой — клип ботов в куполе (`clip_capture scene=null_hall bots=1 seed=29`, 41 с).

Главное: физику подогнали под цифры RM (оседание, отлёт 1–2 H/с, стоп 1 с) и совпали — но **вязкостью**: дамп полёта 1.8
(скорость гаснет за ~0.55 с) при g 1.1 H/с². В RM и JS почти нет ни гравитации, ни сопротивления (JS: g 0.2 H/с², скорость
гаснет за ~1.7 с) — тело летит долго, импульс живёт. Цифры те же, ощущение обратное: бой «в мёде».

| | JS | Godot до ДРАЙВА |
|---|---|---|
| гравитация, H/с² | 0.2 | 1.1 |
| полёт гаснет за | ~1.7 с | ~0.55 с |
| отпустил клавиши | стоп за 0.15 с | выбег 1 с |
| тяга | на голову, конечности хлещут | на торс, кукла летит блоком |
| отлёт после удара | толчок 0.5–1.3 с, отскакивают оба | 1.3–2.5 H/с, гаснет за 1 с; урон ×30 → отлёт ×1.9 |
| удары с hit-stop | почти каждый осознанный | ~17 % |
| камера | всегда на обоих, куклы 40–57 % кадра | на игроке, соперник часто за кадром |
| бот | давит без отступа, зигзаг 0.7 с | ударил — отступил на 1.1–1.5 с |
| крит | — | раз в 35–39 с при бое ~25 с |

В клипе купола: куклы большую часть боя лежат на полу, 18 из 26 стычек взаимные (11 — голова о голову, урон поровну), бой
кончился двойным KO и ничьей; медиана удара 4 HP, 0 критов.

## 2. Что делает ДРАЙВ (числа — `scripts/tuning.gd`, секция «ДРАЙВ»)

| Что | Было | ДРАЙВ | Где |
|---|---|---|---|
| гравитация на куклах | 2.0 м/с² | × 0.35 → 0.7 (gravity_scale частей; оружие и пропсы как были) | `Doll._apply_gravity_scale` |
| дамп управляемого хода | ядро 2.25 / конечности 1.5 | × 0.8 | `Doll._part_linear_damp` |
| тормоз без ввода | 0 | торс +4: ход гаснет за ~0.3 с, кукла висит | `Drive.brake_damp` |
| дамп полёта после удара | 1.8 / 1.5 | 0.7 / 0.6 | `Drive.flight_damp` |
| отброс | clamp(10·D, 100…210) Н·с, потолок 4.5 м/с | 40 + 16·D (≥ 60, ≤ 640), потолок 14 м/с; в торс 0.35 вместо 0.5 | `Drive.knockback_impulse`, `DollCombat._deliver` |
| отдача атакующего | 0.5 × Δv, тяга выкл 0.3 с | 0.7 × Δv, тяга выкл 0.08 с | `Drive.recoil / thrust_lock_s` |
| размен | оба получают полный урон | встречный удар слабее в 1.3 раза — × 0.25; голова о голову — урон по своей скорости налетевшей головы | `DollCombat._drive_trades`, `_contact_doll` |
| запас HP | 100 | 150 (удары сильнее и чаще — бой той же длины) | `Match._drive_hp` |
| замедление | вариант клавиши 0 (А: light с 6 HP) | свой: стоп 45 мс + 0.5× 0.12 с с 2.5 HP, heavy стоп 70 мс + 0.35× 0.3 с («выкл» клавиши 0 главнее) | `HitJuice.variant` |
| heavy | score ≥ 9 | ≥ 8 | `HitTier.classify` |
| крит | кулдауны 8 / 15 с, отлёт 5.5–7.5 м/с | 4 / 8 с, отлёт 9–16 м/с | `HitTier`, `CritLaunch` |
| камера на удар | тряска 0.03 м / 10 HP | × 2.5; толчок кадра в сторону удара на каждом light (3 % полувысоты / 10 HP), heavy × 2.5 | `Match._emit_hit_fx`, `Drive.camera_kick` |
| камера купола | только игрок + стрелка | соперник ближе 7 м — кадр держит обоих (до 9 м), отступы × 0.55, упреждение ≤ 1.2 м | `DynamicCamera` |
| бот кампании | отход 1.1–1.5 с | отход 0.25 с, подход зигзагом (±0.45 каждые 0.7 с) | `RivalBrain._think` |
| вариант управления | — | включая при ТЕЛО → ГОЛОВА-ТАРАН, выключая — обратно ТЕЛО | `Drive.set_on` |

Стиль вспышки («серьёзный»), звук, обломки, цифры и надписи не трогались.

## 3. Замеры (`tests/drive_probe.tscn`, купол Быстрого боя, P1 — «человек» давит, P2 — RivalBrain ур. 3, 5 сидов)

Медианы по матчам, `modes=off,on,seeds=29,7,13,5,41,max_s=85`:

| Метрика | выкл | ДРАЙВ |
|---|---|---|
| удары с откликом времени (стоп / замедление) | 26 % | **69 %** |
| отлёт ЦМ жертвы через 0.1 с: < 5 / 5–12 / ≥ 12 HP, м/с | 2.3 / 1.8 / 2.2 | **3.0 / 4.5 / 7.4** |
| ровные размены (оба получили, меньший ≥ ½ большего) | 21 % | **10 %** |
| криты за бой | 0 | **2** |
| длина боя до KO | 23.7 с | 28.3 с (HP 150) |
| удар ≥ 5 HP | 23 % | 39 % |
| в воздухе | 95 % | 99 % |
| соперник в кадре / кукла от высоты кадра | 92 % / 0.375 | 94 % / 0.363 |
| стычек в минуту / пауза между ними | 61 / 0.75 с | 68 / 0.8 с |

Важно: «человек» пробы давит без остановки, поэтому и без ДРАЙВА бой у него близкий и в воздухе — лежание на полу из клипа
ботов-наскоков проба не воспроизводит. Её смысл — сравнить одно и то же с ДРАЙВОМ и без.

A/B-клип: `img/drive-ab-v1.mp4` (54 с: первые 25 с — ДРАЙВ выкл, дальше вкл; сид 29, тот же «человек» и бот). Без ДРАЙВА бой
прижат к мембране и часто у пола; с ДРАЙВОМ куклы в воздухе посреди купола, конечности хлещут, камера держит обоих.

## 4. Проверки

- `tests/drive_probe.tscn` (headless, ~10 с на 2 × 5 матчей): проверки matches / hits / finite; `strict=1` — цели ДРАЙВА
  (в воздухе ≥ 0.5, размены ≤ 0.3, отклик ≥ 0.5, пауза ≤ 1.5 с, соперник в кадре ≥ 0.6). В окне (через `godot_nofocus.sh`
  и `--write-movie`) пишет A/B-клип; файл настроек автора не трогает.
- `tests/control_feel_panel_snapshot.tscn` (окно): + J → ДРАЙВ вкл, при ГОЛОВЕ вариант не меняется, подпись панели — 8 проверок.
  Заодно исправлено: пробы с окном больше не затирают сохранённые настройки панели автора (`ControlFeel.no_disk`; у worktree
  тот же app_userdata, раньше снимок панели переписывал user://control_feel.cfg).
- С выключенным ДРАЙВОМ поведение то же: `match_probe scene=void` 23.27 с (как до правок), `run_gate`, `run_combat_gate`,
  `run_hitfx_gate`, i18n — зелёные.

## 5. Открыто — решает рука автора

- Нравится ли вообще; какие куски оставить по умолчанию, какие убрать (каждый — отдельная константа `DRIVE_*`).
- Гравитация ×0.35 — меняет решение 28.09 (g = 2.0) только для кукол; табло купола по-прежнему пишет 0.20G.
- Камера держит обоих только вблизи — решение 02.10 «соперника видеть не важно» действует на дальней дистанции.
- HP 150 в ДРАЙВЕ — чтобы бой не стал короче; если бои кажутся долгими — вернуть 100.
- Строгие пробы ощущения (`feel_probe strict`) откалиброваны под RM и с ДРАЙВОМ не гоняются.
