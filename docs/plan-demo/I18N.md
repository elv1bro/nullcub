# Языки игры (02.10.2026)

Задача автора: «сделай всё мультиязычным; в настройках язык, пока русский и английский, но чтобы легко добавить любой». Закрывает п. 5 этапа 14 (`14-n0.md`) и «Настройки: язык» из `11-menu-flow.md`.

## Как устроено

- **Исходный язык — русский, ключ перевода = русская строка из кода дословно:** `tr("Начать бой")`. Код остаётся читаемым, пока выбран русский — словарь не нужен (движок отдаёт ключ как есть; в `project.godot` стоит `internationalization/locale/fallback = "ru"`, иначе без русского файла он подставил бы английский).
- **Остальные языки — по одному файлу `godot/locale/<код>.json`:** `{"@name": "English", "Начать бой": "Start fight", …}`. Ключи на «@» служебные (`@name` — родное название для меню). Пустое значение = «не переведено».
- **Автозагрузка `Loc`** (`scripts/i18n/loc.gd`, стоит перед `Flow`) при старте сканирует `res://locale/*.json`, строит `Translation` на каждый язык и отдаёт их `TranslationServer`. Цепочка запасных вариантов: выбранный язык → английский → русская строка из кода. Поэтому у нового языка достаточно перевести то, что успел.
- **Выбор игрока:** строка «ЯЗЫК» первая в НАСТРОЙКАХ гаража (`GarageSettings`), значение хранится в `user://settings.cfg` (`Flow` → `lang`, по умолчанию `ru`). Список языков строится из найденных файлов, кнопка не требует правок кода. Все подписи гаража построены заранее, поэтому после смены языка гараж перезагружается и снова открывает настройки (`GarageMenu._on_language`). В бою и мастерской язык не меняется — только из гаража.
- **Английские подписи табло** (`FIGHT!`, `KO!`, `FIELD CLEAR!`…) тоже ключи `tr("FIGHT!")`: в ru и en совпадают с самой строкой (как принято в файтингах, N0_VOICE.md п. 4), любой язык может переопределить их строкой в своём файле; русский можно переопределить в `ru.json` (он необязателен и пока содержит только `@name`).
- **Названия деталей/материалов/чертежей:** в `.tres` лежит русский `title` (ключ). `PartDef`, `MaterialDef`, `BodyBlueprint`, `WeaponBlueprint` отдают его через геттер `title` уже переведённым (хвост « *» «не сохранено» не переводится). Имена кита для игрока — `PartNames.NAMES` (`of()` переводит).
- **Реплики N0:** `N0Lines.LINES` хранит только русские строки, английские (утверждённые автором) лежат в `locale/en.json`.

## Как добавить язык

```bash
python3 godot/tools/i18n.py new de Deutsch      # создаст godot/locale/de.json со всеми ключами (значения пока английские)
# переписать значения на немецкий — можно частично, остальное покажется по-английски
python3 godot/tools/i18n.py status              # сколько переведено
python3 godot/tools/i18n.py check               # те же подстановки (%s %d), нет русских букв в переводе
```

Всё. Язык появится в НАСТРОЙКАХ сам. Чего нет в файле — идёт из английского. Подстановки `%s`, `%d`, `%.1f` переводчик оставляет как есть (порядок можно менять только через `%s` одного типа — движок подставляет по порядку, поэтому порядок слов лучше сохранять или собрать фразу иначе).

Шрифты (Oswald, Rubik, JetBrains Mono) покрывают латиницу и кириллицу. Для CJK, арабского, деванагари нужен запасной шрифт: добавить файл в `assets/fonts/` и дописать его в `fallbacks` трёх шрифтов гаража (`GarageMenu._font`, `Flow.head_font`). Пока не сделано, потому что таких языков нет.

В экспорте файлы языков — `.json`: в пресет экспорта нужен `include_filter="locale/*.json"` (пока пресетов нет; без фильтра `Loc` падает на встроенные `ru`/`en`, остальные языки пропадут).

## Правила для кода

1. Любая подпись, которую видит игрок, — через `tr("…")` (в `static func` — `TranslationServer.translate("…")`, `tr()` там не вызвать). Формат после перевода: `tr("Урон: %d") % x`, не `tr("Урон: %d" % x)`.
2. В `const` и в аннотациях (`@export_group`) `tr()` не работает: в таблице лежат русские ключи как есть, а переводятся в месте использования — `tr(ROWS[i]["title"])`.
3. Не сравнивать и не искать по переведённому тексту (`msg.contains("энерги")`) и не использовать русскую строку как идентификатор (ключ словаря, `match`). Для логики — коды (id, enum, bool), текст только для показа.
4. Склейка `"Урон " + str(x)` ломает порядок слов в других языках — собирать одной строкой с подстановкой.
5. Множественные числа: не склонять по числу (`1 деталь / 2 детали`), писать нейтрально: «Деталей: %d» → «Parts: %d».
6. `Label`/`Button` с готовым русским `text` в `.tscn` переводятся движком сами (Control.auto_translate), в сцене править ничего не нужно.
7. Отладочные `print`/`push_*` не переводятся и в проверку не попадают.

## Проверки

- `python3 godot/tools/i18n.py check` — у каждой русской/английской строки кода есть перевод во всех языках, подстановки совпадают, нет «висячих» ключей (ошибка — код возврата ≠ 0).
- `godot --headless --path godot res://tests/i18n_probe.tscn` — все скрипты компилируются (ловит `tr()` в `const`/static), языки читаются, переключение ru ↔ en работает, подстановки совпадают.
- `godot --path godot res://tests/i18n_scenes_probe.tscn` — сцены под английским не показывают кириллицу в Label/Button/RichTextLabel (окно не нужно, headless тоже работает).
