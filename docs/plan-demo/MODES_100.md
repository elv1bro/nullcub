# 100+ режимов, мастерская без утомления, рисованный робот — план (08.10.2026)

Автор 08.10 (близко к тексту):

> Хочу сделать более 100+ режимов игры разных. Облегчить работу в мастерской (может тоже на тестирование разные режимы, сейчас это
> утомляет, как сделано). Может по фану было бы прикольно рисовать робота, а потом он появляется уже деталями, типа собирается.
> Надо жечь лимиты максимально, есть 20 часов.

Решения сессии (без ответа автора, по умолчанию; поправить — одной строкой в чате):

1. **100+ режимов — не 100 отдельных сцен, а реестр «основа × модификаторы».** Основ восемь (они уже в игре: дуэль, купол, бомба,
   гонка, спорт ×3, стычка, PvE, стазис), модификаторов ~40 (гравитация, скорость, запас, урон, суставы, время, предметы, боты, кадр).
   Режим = именованная карточка: основа + карта + набор модификаторов + свои числа. Карточки пишутся руками (каждая со своим именем
   и описанием, не «дуэль + 3 флага»), сейчас их 100+, и добавить новую — три строки в `scripts/modes/mode_catalog.gd`.
   Любой режим запускается из одного экрана «РЕЖИМЫ» (поиск, теги, случайный, избранное, последние).
2. **Мастерская: «Испытать в режиме…»** — та же кукла, что на стенде, сразу уходит в любой режим реестра (клавиша Y или кнопка рядом
   с «Испытать»), а после боя возвращается в мастерскую с тем же чертежом. Плюс панель испытания прямо в зале (T): противник-бот
   (уровень, 0–3 штуки), гравитация, прочность суставов, запас, всё по горячим клавишам, без перезахода.
3. **Рисованный робот** — отдельный экран «Нарисуй бойца»: рисуешь мышью силуэт, игра разбирает штрихи на торс / голову / конечности,
   подбирает детали кита и собирает куклу у тебя на глазах (детали прилетают с полки на якоря, искры, щелчки), чертёж открывается
   в мастерской. Прототип — одна сцена + проба на распознавание фигур-эталонов.

## A. Устройство реестра

```
scripts/modes/mode_def.gd      # карточка: id, name, desc, base, scene, tags, mutators: [{id, args}], params
scripts/modes/mutators.gd      # каталог модификаторов: id → {name, desc, apply(ctx), tick(ctx, dt), on_doll(ctx, doll)}
scripts/modes/mode_catalog.gd  # 100+ карточек руками (+ generate(): случайная и «режим дня»)
scripts/modes/mode_run.gd      # autoload ModeRun: launch(def) → Loading.change_scene(scene) → ждёт Match в дереве → apply
scenes/menu/modes_menu.tscn/gd # экран «РЕЖИМЫ»
tests/modes_probe.gd/tscn      # проба
```

Контекст модификатора `ctx`: `{match, dolls, arena, field (NullField|null), scene, params, rng}`. Раннер переприменяет
`on_doll` на `Match.doll_replaced` (возрождение) и на `phase_changed(COUNTDOWN)` (R — заново), снимает всё на выходе из сцены.

## B. Мастерская

- Клавиша **Y** / кнопка «В режиме…» рядом с «Испытать»: список карточек (тот же экран «РЕЖИМЫ» поверх мастерской, с пометкой «кукла
  со стенда»). Запуск: `ModeRun.launch(def, {"player_blueprint": blueprint})`; раннер подменяет P1 на `ModularDoll` из чертежа
  (так уже делают гонка и стычка). После боя — `Flow.to_menu(МАСТЕРСКАЯ)`, чертёж из автосейва.
- Панель испытания в зале: `Tab` — показать/спрятать; строки: бот (0/1/2/3 и уровень), гравитация (0/0.5/1/2.5/вбок), суставы (C),
  запас (;), бочки, оружие. Всё — те же модификаторы реестра, применяются к зоне испытания без перезахода.

## C. «Нарисуй бойца»

Сцена `scenes/workshop/doodle_bot.tscn`:
1. Холст 2D (Line2D-штрихи, ластик, очистить). Подсказка силуэтом «Человека» под холстом (включается/выключается).
2. Разбор: растеризация штрихов → скелетизация (утоньшение) → граф ветвей; самая «толстая» область — торс; ветвь вверх от торса —
   голова; две ветви вбок — руки (два сегмента по длине); две вниз — ноги. Толщина штриха → материал/деталь (толстый — броня/котёл).
3. Сборка: из разобранного скелета — `BodyBlueprint` (детали кита по ролям, длина ветви → число сегментов, толщина → материал);
   анимация: детали вылетают с полки по очереди к своим якорям, щелчок, искра, в конце кукла «оживает» и пожимает плечами.
4. Кнопка «В мастерскую» → чертёж открыт на стенде; «Испытать» — сразу в зал.
Проба `doodle_probe`: 6 эталонных рисунков (человек, широкий, высокий, без рук, с хвостом, каракули) → ожидаемые роли деталей.
