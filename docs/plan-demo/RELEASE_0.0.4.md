# NULL GRAVITY — тестовая сборка 0.0.4 (11.10.2026)

Четвёртая общая сборка. Живёт в ветке **`main`** (тег `v0.0.4`). Не готовое демо, а сборка для тестирования автором. Слиты две линии:
локальная (06.10: пакет режимов, проход по картинке, экран «ВСЕ РЕЖИМЫ», ролики для Steam) и облачная (08–10.10: шесть режимов, реестр
«РЕЖИМЫ», испытание в мастерской). Почти всё новое руками ещё никто не играл — проверено пробами.

## Как запустить на Mac
Как в `RELEASE_0.0.2.md` (Godot 4.7.2, двойной клик по `play-mac.command`):
```bash
git clone https://github.com/elv1bro/nullcub.git && cd nullcub     # или: git checkout main && git pull
./play-mac.command                # или play-latest.command: подтянуть main и запустить
```
Первый запуск после обновления дольше: скрипт делает `--import` (новые сцены режимов, снимки «ВСЕ РЕЖИМЫ», шайба, клюшка).

## Исправлено при сборке (11.10)
- **Шесть звуков без файлов.** В git лежали только `.import` от удалённых в `380abb2` файлов (`thud/hit_19_low`, `hit_35_low`,
  `inhale/inhale_rev_01/02`, `creak/fiber_creak_01/02`); `sfx_director.tscn` ссылался на них, `make_layer()` в `sfx_director.gd` подбирал
  их по списку файлов папки — сцена звука не грузилась, пробы со счётчиком ошибок движка (`bomb_probe`, `workshop_probe` и др.) краснели.
  Ссылки и `.import` убраны; `sfx_probe` 39/39.
- **Клавиша «/» в двух ролях.** Фоторежим (`cam_photo`, проход по картинке) и рука P2 (головоломки, Перегон, P2-человек в перетягивании)
  жили на одной клавише: в головоломке «/» ставила игру на паузу вместо хвата. Режим, где «/» занята, ставит себя в группу
  `PhotoMode.KEY_TAKEN_GROUP` — фоторежим уступает (`look_cam.gd`). Новая проба `photo_key_probe` (до правки 12 FAIL, после — OK).
- **Канат: синий бот не брал канат** (`tug_probe` `rope_holds_10s`, было «оба держат 0.0 из 10 с»). У куклы human одна рука мышью —
  Hand_R, и её плечо у обеих команд с одной стороны (кукла смотрит в камеру, не разворачивается). Левый (синий) бот тянулся к канату
  дальней рукой через корпус, плечо упиралось в лимит, кисть висела ≈ 0.45 м над звеном и не подходила на `GRAB_CLOSE_M` (0.1 м).
  Теперь бот берёт кисть со стороны каната: `TugBrain.rope_hand()` → новый `ArmAssist.set_control_part()` (отпустить, вернуть позу,
  собрать цепь и IK заново). В облаке 10.10 проба была зелёной — там дальняя рука, видимо, дотягивалась на пределе; теперь от машины
  не зависит. После правки 23/23: оба держат 9.1 из 10 с, матч ботов 3 : 1 за 32 с (цель 20–60), сильный бьёт слабого 5/5.
  Человек P1 слева по-прежнему тянет Hand_R (ЛКМ, дальняя рука) — хват человека с радиусом 0.4 м, не проверено руками, удобно ли.
- **`workshop_probe` 3 красные → 239/239.** Две проверки отстали от игры: с 06.10 «запас из деталей» — стандарт, ядро и голова
  не стоят энергии, human = 72, а не 82 (`WORKSHOP_V4.md`); проба теперь берёт 72 или 82 по `PartHp.on`. Третья (`test_weak_contact`)
  тянула руку к манекену сразу после серии ударов, а куклу отбрасывает от него на 2+ м — рука не доставала. Теперь кукла сначала
  подходит на длину руки. Сигнал «слабое касание» в игре работал (проверено: касания манекена приходят, урон 0).
- **`i18n_layout_probe`: тост «Подъёма» не проверялся.** Проба звала ключ `"P2 сорвался: %.1f м вниз"` с двумя числами, в игре —
  `"P%d сорвался: …"`; формат падал с ошибкой движка, тост проверялся неполным (проба при этом не краснела). Ключ в пробе исправлен.

## Решения автора (не блокируют)
- **Заражение:** боты-заражённые заражают всех за 10–60 с из 90, здоровые ни разу не дожили — ускорение заражённых, паузу касания или длину партии?
- **Царь горы:** между ботами зона спорная ~75 % времени, до 60 очков никто не доходит — радиус зоны, порог, длина матча?
- **Хоккей:** боты забивают за 15–36 с (ворота — вся стена до 1.2 м, шайба почти не тормозит) — тормоз шайбы, ворота ниже?
- **Охота за головами:** матч ботов кончается по времени при 8–15 очках на двоих — цель 10 ниже или время дольше?
- **5×5:** 10 кукол — тяжело для физики; если в окне тормозит — 4×4.
- **Канат:** удобно ли тянуть руку мышью к канату на полу; P2 без мыши — клавиша «/».
- **Режимы 06.10:** вопросы к автору — в `MODES_PACK.md` и документах режимов (гольф — весело ли; Перегон и Подъём — это только пробы
  первого шага).
- **Картинка:** открытые вопросы — `LOOK_PASS.md` (облёт на KO по умолчанию, заставка на каждом лоадере, луч прожектора).
- Не начаты (из выбранных 08.10): «Собери себя» (черновик в ветке `claude/mode-scavenger`), Босс, Захват точек, Испытание, Вышибалы;
  мастерская — «Нарисуй бойца», панель испытания (Tab), бой A/B, «зачем мне эта деталь», случайный боец, свечение в покраске.
