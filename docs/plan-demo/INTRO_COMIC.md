# Заставка-комикс (интро перед игрой)

> **30.09.2026:** сюжет заставки (Башня, свалка) — архив, лор сменён на `LORE_NULL.md`. Движок страниц, 3D-кадры и звук годятся для новой заставки; предложение по интро — выход бойца на арену (`LORE_NULL.md`, «Первое, что идёт в демо»).

Запрос автора 28.09.2026: «красивая заставка-комикс в начале игры, как в ААА», референс — лист из 13 панелей
(кукла просыпается на свалке → смотрит на Башню → находит деталь → арена → бой).

Итог v1: `godot/scenes/intro/intro_comic.tscn` — главная сцена проекта, после неё игра переходит в
`scenes/playground_scrap.tscn`. Видео: `img/intro-comic-v1.mp4` (60 с, со звуком), страница целиком:
`img/intro-comic-v1-page.png`, финал с логотипом: `img/intro-comic-v1-title.png`.

## Как это устроено

Это «моушн-комикс»: страница из 13 панелей в три строки (4 / 5 / 4, как в референсе), и каждая панель — не картинка,
а кадр 3D-мира, снятый движком на настоящих ассетах игры (арена «Свалка», кукла v3, хлам листов 01–02).

1. **Холодное открытие.** Пока площадка грузится (5–7 с), на чёрном печатается журнал Башни
   (`TOWER//SYS :: DISPOSAL UNIT 0 … SCANNING FOR ACTIVE CORES`). Загрузка спрятана в сюжет.
2. **Страница.** Камера страницы наезжает на панель, панель проявляется рваной чернильной кромкой, внутри играет кадр
   (камера CamA → CamB, позы куклы, события), появляются надписи. Кадр кончился — панель застывает картинкой,
   камера идёт к следующей. После строки — общий план строки; в конце вся страница, удар логотипа RAGDOLL MASTER.
3. **Печать.** 3D-кадр → чернильный контур по разрывам глубины и нормалей (`shaders/comic_ink.gdshader`,
   только линии поверх кадра, частицы не пропадают) → в панели растр в тенях, раздельное тонирование, зерно, виньетка
   (`shaders/comic_panel.gdshader`). Растр задан в пикселях страницы: при наезде точки растут, как на бумаге.
4. **Надписи** (`comic_letter.gd`): звукоподражания в три слоя обводки с «выстрелом» масштаба, таблички голоса Башни
   (янтарный моноширинный текст печатается по буквам), штрихи испуга, звёздочки, звезда удара, линии скорости и фокуса.
   Надписи с якорем (`hero:Head`, `prop:Barrel`…) следят за точкой 3D-кадра, пока панель живая.
5. **Звук** (`assets/audio/intro/`, синтез `tools/gen_intro_audio.py`): ветер Свалки петлёй, перелёт камеры, печать
   и сигнал табличек, BONK / CLICK / CLANK / BAM, рассыпание куклы, удар логотипа. Звуки временные — файлы с теми же
   именами можно заменить настоящими.

Производительность: 3D рендерит одна SubViewport размером с панель на экране (≤ 1920 px), только текущая панель;
прошлые — застывшие текстуры с mip-уровнями. Кадр как в игре на арене «Свалка».

## Раскадровка

Голосов два, как в `LORE.md`: Башня (системные строки капсом) и звукоподражания. Правило гашения соблюдено:
героический взгляд на Башню → сразу бочка на голову.

| # | Кадр | Надписи и звук |
|---|------|----------------|
| 01 | Свалка на закате, сверху сыплется хлам | SECTOR 0 // THE SCRAP · DISPOSAL CYCLE: COMPLETE · дождь хлама |
| 02 | Кукла лежит в куче, правого предплечья нет, корона на Ядре мерцает | tk… tk… · CORE SIGNAL DETECTED · **UNKNOWN CORE.** |
| 03 | Резко садится, глаза загораются | «!» + штрихи испуга |
| 04 | Снизу вверх: кукла на вершине кучи смотрит на башню против солнца | RETURN TO THE WORKSHOP. |
| 05 | Запоздавшая бочка надевается на голову | BONK! + звёздочки |
| 06 | Вытаскивает из кучи рук-ног чужое предплечье (орех, красные обмотки прежнего хозяина) | shhk! |
| 07 | Поднимает деталь к солнцу | тишина |
| 08 | Прикручивает к локтю, смотрит на новую руку | CLICK! · COMPONENT ACCEPTED. |
| 09 | Летит над настилами к флагам короны | NEW CONTESTANT DETECTED |
| 10 | Арена: сверху падает Разборщик (орех, шлем, старый топор) | CLANK! · BOUT 001 :: FIGHT! |
| 11 | Крупно: глаза-щёлки, кулаки | линии фокуса |
| 12 | Рывок и удар, враг рассыпается на детали (замедленно) | линии скорости → BAM! + вспышка |
| 13 | Парит над обломками | WINNER: UNKNOWN CORE |
| — | Вся страница, логотип | RAGDOLL MASTER · THE TOWER CANNOT CHANGE. YOU CANNOT STOP. |

Лор-связки: «UNKNOWN CORE» — у куклы нет карточки в реестре (лицо-фотография ещё не наклеено, голова пустая);
чужая рука — сборка тела из хлама (Anchor → Component); Разборщик — враг листа 01; разлёт на части — KO игры.

## Как править

- **Камеры и куклы кадра:** открыть `intro_stage.tscn`, узел `Shots/ShotNN`: `CamA` / `CamB` — начало и конец
  наезда (у Camera3D есть Preview), `HeroA/HeroB`, `EnemyA/EnemyB` — где стоит кукла, `Props` и `Lights` — только
  этого кадра. Таймлайн — строки в инспекторе ComicShot (`hero_keys "0:lying"`, `events "0.6:drop:Barrel:0.45:4.0"`),
  список событий — в комментарии `IntroStage._apply_events()`.
- **Позы:** `comic_poses.gd` (оси: X− — конечность вперёд, Z+ — левая наружу, локоть X−, колено X+).
- **Панели и надписи:** `intro_comic.tscn`, узлы `Page/PanelNN` (форма — `polygon`), надписи — дети `Letters`
  (и `Art/Clip` — обрезаются по панели). Текст, время, размер и цвета — в инспекторе ComicLetter.
- **Внимание:** `tools/build_intro_comic.gd` пересобирает сцены целиком — ручные правки в редакторе он перезапишет.
  Либо правим в редакторе и больше не пересобираем, либо переносим правки в таблицы builder-а.
- Пересборка: `godot --headless --path godot -s res://tools/build_intro_comic.gd` (после новых `class_name` сначала
  `godot --headless --path godot --import`).
- Следующая сцена — `next_scene` у корня `intro_comic.tscn`. Показывать только первый раз — `play_once = true`
  (флаг `user://intro_seen`, аргумент `-- intro=1` показывает всё равно).

## Управление

Пробел / Enter / клик / A — досмотреть текущую панель сразу. Удерживать (0.8 с) или Esc — пропустить всю заставку.
Аргументы после `--`: `intro_skip=1` — сразу в игру, `intro_speed=4` — ускорить, `intro_capture=<папка>` — режим записи.

## Проверки

```bash
# вся заставка: PNG страницы после каждой панели и в финале + intro_report.json (каждая панель застыла непустой), exit 0/1
godot --path godot --resolution 1600x900 res://scenes/intro/intro_comic.tscn -- "intro_capture=/абс/папка"
# видео со звуком (Movie Maker), потом ffmpeg → mp4
godot --path godot --resolution 1280x720 --write-movie /абс/intro.ogv --fixed-fps 30 res://scenes/intro/intro_comic.tscn -- "intro_capture=/абс/cap"
# отдельные кадры площадки в конце кадра (+ координаты головы/рук/стоп для наведения камер)
godot --path godot --resolution 640x360 res://tests/intro_snapshot.tscn -- "shots=1-13,at=1.0,w=960,out=/абс/папка"
# переход в игру: проект с главной сцены, ускоренно
godot --path godot --quit-after 7000 -- "intro_speed=4"      # в логе: IntroComic → res://scenes/playground_scrap.tscn
```

Прогон v1 (29.09): отчёт ok, 13/13 панелей непустые, площадка грузится 6 с (с `use_sub_threads`; без них — 24 с),
вся заставка ≈ 60 с, переход в игру без ошибок.

## Открыто

- Арена «Свалка» сама грузится ~12 с headless (кучи хлама по 0.3–0.8 с каждая) — отдельная задача; заставка это прячет,
  но первый запуск игры всё равно ждёт.
- Площадка — это живая арена `scrap.tscn`: если её перестроят (параллакс v2 и т.п.), композиции кадров надо проверить
  прогоном `intro_snapshot` и поправить камеры.
- Лица-фотографии в заставке нет (голова пустая = UNKNOWN CORE). Когда появится этап 10, можно добавить финальный кадр
  «фото наклеено на голову».
- Звуки синтетические, музыки нет. Длительность 60 с — при желании сократить `duration` кадров и `hold` панелей.
