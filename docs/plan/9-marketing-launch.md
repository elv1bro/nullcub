# 9 — Маркетинг, запуск, live-ops

Цель: 10 000+ wishlist к релизу → успешный запуск → удержание 1000 DAU.
Это не «после разработки» — идёт параллельно с этапами 5–8.

## 9.1 Виральный контур (встроен в игру)

Главный маркетинговый актив — сама игра генерирует контент:

- [ ] **Кнопка «Клип»**: последние 15 секунд боя + лицо игрока PiP → mp4/gif
  (MediaRecorder). Из ROADMAP этап 4 — теперь это релиз-блокер.
- [ ] Killcam с реальным лицом в момент нокаута.
- [ ] Автопостер результата боя («обложка комикса») с кнопкой share.
- [ ] Водяной знак с названием игры на всех экспортах.

## 9.2 Бесплатная веб-версия = маркетинговый канал

- [ ] Веб-версия остаётся бесплатной с урезанным контентом
  (1 арена, 3 оружия, без кампаний) + кнопка «Полная версия в Steam».
- [ ] Публикация на itch.io, Poki/CrazyGames (у них миллионы игроков,
  физика-приколы там заходят) — каждая площадка со ссылкой на Steam.

## 9.3 Wishlist-кампания (3–6 месяцев до релиза)

- [ ] Страница Steam запущена (этап 8) — точка отсчёта.
- [ ] TikTok/YouTube Shorts/Reels: 2–3 клипа в неделю из игры
  (смешные нокауты, странные монстры из мастерской). Это игра, которая
  сама производит такие клипы — использовать.
- [ ] Reddit: r/WebGames, r/IndieGaming, r/PhysicsGames — посты-гифки.
- [ ] Discord-сервер: плейтесты, обмен блюпринтами, канал скриншотов.
- [ ] Рассылка ключей микро-стримерам (100–5000 зрителей, категория
  «игры с друзьями/приколы»). Пати-игры продают стримы.
- [ ] **Steam Next Fest** с демо — главный одиночный буст wishlist.
  Демо = туториал + 3 арены + мастерская + бой дня.

## 9.4 Запуск

- [ ] Дата: не в окно AAA-релизов; вторник–четверг.
- [ ] Цена: $4.99–9.99 (пати-физика, сравнимые: Gang Beasts $19.99,
  Stick Fight $4.99 — ближе ко второму) или F2P + косметика
  (решить до Next Fest по фидбеку демо).
- [ ] Launch discount 10–15%.
- [ ] Пресс-кит: gif-ы, скриншоты, факты, контакты.
- [ ] День запуска: пост во все каналы, стримеры с ключами заранее.

## 9.5 Live-ops после релиза (удержание 1000 DAU)

- [ ] Недельный цикл: новый босс недели + модификатор боя дня — автоматом
  из сида (этап 5), без ручной работы.
- [ ] Ежемесячно: 1 контент-дроп (арена или 2–3 оружия) + пост в Steam News.
- [ ] Быстрые патчи: краши/эксплойты < 48 часов.
- [ ] Витрина Steam Workshop: featured-блюпринты недели.
- [ ] Сезонные ивенты (Хэллоуин-арена, новогодние лица) — переиспользование
  механик с новой косметикой.

## 9.6 Метрики (что считаем)

- Wishlist rate (цель: 500+/нед во время кампании, 3000+ за Next Fest).
- Демо: медиана длины сессии > 15 мин; конверсия демо → wishlist > 20%.
- После релиза: D1 > 35%, D7 > 15%, D30 > 8%; медиана сессии > 20 мин.
- Отзывы: держать > 80% положительных (быстро отвечать на негатив с багами —
  и чинить).

## 9.7 QA-чек-лист перед каждым билдом (ручной, 10 минут)

1. Меню: Play → бой → Esc → Play снова (застревание навигации).
2. Мастерская: монстр → тест физики → возврат → бой → победа → медаль.
3. Мастерская: оружие → сохранить → оно в следующем бою.
4. Двойной KO → экран ничьей.
5. Рематч ×3 → урон и захваты работают.
6. Кампания: глава → перезагрузка → прогресс на месте.
7. Онлайн: комната → бой → обрыв сети → корректный финал.
8. Геймпад: полный путь меню → бой → меню без клавиатуры.

## Критерий успеха (вся стратегия)

- 10 000+ wishlist к релизу.
- Первая неделя: 5 000+ продаж (или 50 000+ установок F2P).
- Через месяц: стабильные 1000+ DAU, > 80% положительных отзывов.
