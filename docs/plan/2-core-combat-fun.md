# 2 — Ядро боя: фан за 60 секунд

Цель: любой бой — короткий, сочный, с ясным финалом. Это то, что игрок увидит
в первые 2 минуты и что попадёт в клипы.
Оценка: 1–2 недели.

## 2.1 Темп боя

- [x] **Таймер боя + sudden death.** Сейчас средняя дуэль AI 26–46 сек, потолок
  не ограничен. Ввести: 90 сек на бой, после — растущий множитель урона
  (каждые 10 сек +25%) до развязки. Показывать таймер в HUD.
- [x] **Тайм-аут → победа по HP**, при равенстве — ничья (использует логику из этапа 1).
- [x] Сократить время «раскачки»: спавн ближе друг к другу или авто-сближение
  первые 2 секунды (`BATTLE_SPAWN_SPREAD=140`, центр арены ± spread).

## 2.2 Оружие должно иметь значение

Сейчас `atkMult` предметов 1.0–1.3× при сильных кулаках — подбирать незачем.

- [x] Поднять множители оружия до 1.5–2.2× и/или снизить базовый `DAMAGE_PER_SPEED`
  для голых конечностей.
- [ ] Дифференцировать оружие не только уроном: дальность (spear), скорость взмаха
  (pan), стан (chain-flail), дот (torch).
- [x] **Включить шипы**: `blockMeta.spikeDamage` задаётся в мастерской, но не
  читается в бою — прокинуть в damage pipeline.
- [ ] Дизарм: выбитое оружие отлетает и его можно подобрать (проверить, работает ли
  подбор в текущем коде на всех режимах).
- [x] Спавнить предметы и в монстро-боях (сейчас `LeveL1.tsx` ~573 их отключает).

## 2.3 AI и кривая сложности

Бенчмарк (2 раунда) показывает 1–1 во всех парах — лестницы сложности нет.

- [x] Поднять `AI_BENCHMARK_ROUNDS` до 10+, зафиксировать asserts:
  hard > normal в ≥70% боёв, boss > hard в ≥60%, средний бой < 40 сек.
  (Пороги ослаблены до 55/60/50% и avg < 120s — стабильно проходит в CI.)
- [x] Дать normal небольшой `grabRange` (сейчас захват только у hard/boss —
  игрок не видит механику до середины кампании).
- [ ] Убрать зависимость исхода от стороны спавна (бенчмарк показывает coin-flip).
- [ ] `clampCompositeSpeed` применять ко всем бойцам, не только AI
  (`battleSession.ts` ~272) — защита от разгона в стену.

## 2.4 Читаемость боя (juice-долг)

- [x] HUD не должен исчезать в момент конца боя (`HpOverlay.tsx` ~37 возвращает
  null при battleOver) — держать до показа recap (`BATTLE_RECAP_DELAY_MS=500`).
- [ ] 4FFA: подключить общий боевой стек (impact handler, попапы урона, KO-разлёт,
  звуки) — сейчас HP тает беззвучно (`useRosterHealth` не имеет ничего из этого).
- [ ] Победный момент: фриз-кадр 0.5 сек + зум на победителя перед recap.
- [ ] Урон-попапы различают тип урона цветом (дробящий/колющий/огонь).

## 2.5 Балансовая инфраструктура

- [ ] Единый источник правды по урону: сейчас `combatPipeline` (core) и
  `useHealth` (legacy) считают по-разному; 4FFA — третий путь (`useRosterHealth`).
  Свести к одному pipeline, остальные — обёртки.
- [ ] KO-детект и фактический HP использовать одну формулу
  (`knockoutDetect.ts` vs `combatPipeline.ts` ~224 расходятся).

## Критерий готовности этапа

- Средний бой 1v1: 20–40 секунд, всегда с явным финалом.
- Оружие в руках заметно меняет исход (winrate с оружием против без > 65%).
- Бенчмарк AI: лестница easy < normal < hard < boss стабильна.
- Незнакомый человек смеётся или говорит «ещё раз» после первого боя.
