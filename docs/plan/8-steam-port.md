# 8 — Steam-порт

Цель: та же игра — нативным приложением в Steam, со страницей, ачивками,
облаком и обязательно Steam Deck.
Оценка: 2–3 недели чистой работы + месяцы жизни страницы (начинать РАНО:
страница должна собирать wishlist задолго до релиза).

## 8.1 Упаковка

В репо уже есть папка `electron/` — проверить состояние и довести:

- [ ] Electron-сборка: окно, иконка, fullscreen, отключить DevTools в проде.
- [ ] Альтернатива — Tauri (легче, но steamworks-биндинги хуже); решить один раз.
  Рекомендация: **Electron + steamworks.js** (проверенный путь).
- [ ] Оффлайн-режим: игра работает без сети (кроме онлайн-дуэлей).
- [ ] Билды: Windows (обязательно), Linux (для Deck — Proton обычно хватает,
  но проверить), macOS (опционально).
- [ ] Автообновление через Steam (депоты), не своё.

## 8.2 Steamworks-интеграция

- [ ] steamworks.js: init, overlay (важно: в Electron оверлей требует флагов GPU —
  проверить первым делом, это известная боль).
- [ ] **Ачивки** — замапить существующие 12+ медалей на Steam Achievements.
- [ ] **Steam Cloud** — синк localStorage-прогресса (кампания, стрики, библиотека
  мастерской). Требует версионирования схемы из этапа 1.
- [ ] **Leaderboards** — время боя дня, недельный босс (этап 5).
- [ ] **Steam Workshop** (после релиза) — публикация блюпринтов монстров/оружия/
  арен. Это огромный ретеншн-рычаг для нашей игры.
- [ ] Rich Presence: «Дерётся с Боссом дня».

## 8.3 Ввод и Steam Deck

- [ ] **Полная поддержка геймпада** (сейчас клавиатура): движение, удары,
  меню-навигация. Steam Deck Verified резко поднимает видимость.
- [ ] Glyphs кнопок геймпада в подсказках.
- [ ] Вебка на Deck отсутствует — авто-fallback на синтетическое лицо
  (код уже есть, проверить путь).
- [ ] Целевые 60 FPS на Deck (профилировать Matter.js; лимит тел на арене).

## 8.4 Страница магазина (запускается СЕЙЧАС, не в конце)

- [ ] Steamworks-аккаунт, app fee ($100).
- [ ] Капсулы/арты: главная фишка на первом кадре — рожи с вебки + рэгдоллы.
- [ ] Трейлер 30–60 сек: 80% геймплей-моменты (нарезка клипов), 0% логотипов.
- [ ] GIF-ы для описания (движение продаёт физику лучше скриншотов).
- [ ] Теги: Physics, Ragdoll, Local Multiplayer, Funny, Fighting, Sandbox.
- [ ] Описание ru + en. Целевая аудитория en-first (объём рынка).
- [ ] «Coming soon» страница живёт минимум 3–6 месяцев до релиза
  (максимум времени на сбор wishlist).

## 8.5 Юридическое / организационное

- [ ] Проверить лицензии всех ассетов (шрифты Rubik/Unbounded — OFL, ок;
  звуки/музыка — только с правом коммерческого использования).
- [ ] Privacy policy: вебка обрабатывается локально, никуда не передаётся —
  большой плюс, написать это явно.
- [ ] Возрастной опросник Steam (мат в banter-фразах → выставить галки;
  учесть настройку «Без цензуры 18+»).

## Критерий готовности этапа

- Игра ставится из Steam, запускается, оверлей работает, ачивка падает.
- Прогресс переживает переустановку (Cloud).
- Играбельно на Steam Deck с геймпадом от меню до боя.
- Страница опубликована и собирает wishlist.
