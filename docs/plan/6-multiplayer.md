# 6 — Мультиплеер: стабильный онлайн 1v1 (+ пати)

Цель: два человека в разных городах играют без танцев с бубном.
Онлайн — сильнейший драйвер DAU и сарафана.
Оценка: 2–4 недели (самый рискованный этап, начинать рано).

## 6.1 Выбрать один стек (сейчас их два)

| Стек | Состояние | Решение |
|---|---|---|
| WebSocket-дуэли (`WsSessionContext`, `gameRoom.ts`, `BattleDedicated`) | Рабочий прототип: комнаты, ready-up, авто-старт, room secret | **Основной** |
| WebRTC P2P (`NetSessionContext`, `MultiplayerLobby`, `BattleNetwork`) | Легаси; гейт `VITE_ENABLE_P2P` (default off); guest HP sanitize | Заморозить; удалить после релиза или оставить для голоса/видео |

- [x] Задокументировать решение; гейт P2P/FFA в `BattleRouter` + `MultiplayerLobby` (`featureFlags.ts`).
- [ ] Выпилить мёртвый P2P-код целиком (после релиза WS).

## 6.2 Надёжность WS-дуэлей

- [ ] Reconnect: обрыв сети ≤ 10 сек → возврат в бой, иначе техпоражение.
- [ ] Обработка «оппонент вышел»: победа + понятный экран, не зависание.
- [ ] Валидация инпутов на сервере (`server/gameRoom.ts`) — не доверять клиенту.
- [ ] Спектатор-слот: третий в комнате смотрит (дёшево, а стримеры любят).
- [ ] Кастомный контент в онлайне: блюпринт монстра/оружия передаётся при
  старте комнаты (это уникальная фишка — «дерись моим монстром против моего»).

## 6.3 Матчмейкинг-минимум

- [ ] Кнопка «Быстрый матч»: очередь на сервере, пара по первому свободному.
- [ ] Приватные комнаты по коду (уже есть) — довести UX: копирование ссылки,
  вход по ссылке из браузера.
- [ ] Регион/пинг показывать до старта.

## 6.4 Хостинг

- [ ] VPS с WS-сервером (Node), автодеплой из репо.
- [ ] Мониторинг: онлайн-счётчик, логи комнат, алерты на падения.
- [ ] Нагрузочный тест: 100 одновременных комнат.

## 6.5 Пост-релиз (не блокирует запуск)

- Голос по радиусу (1/d²) и видео-кружки — из ROADMAP этап 6; вернуть WebRTC
  поверх WS-сигналинга.
- Турниры на 4–8 человек.

## Критерий готовности этапа

- 2 игрока из разных сетей: комната → бой → рематч ×3 без единого зависания.
- Обрыв соединения никогда не оставляет игрока на мёртвом экране.
- 20 боёв подряд на проде без рестарта сервера.
