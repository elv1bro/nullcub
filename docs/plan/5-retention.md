# 5 — Ретеншн: повод заходить каждый день

Цель: превратить «поиграл разок» в ежедневную привычку. Без этого 1000 DAU
недостижимы ни при каких продажах.
Оценка: 2–3 недели. Можно параллельно с этапами 6–7.

Принцип: **не рисуем новый контент — комбинируем существующий**
(монстры × модификаторы × арены × правила = сотни уникальных дней).

## 5.1 Бой дня (ядро ретеншена)

- [ ] Сид из даты (`YYYY-MM-DD`) детерминированно выбирает: противника
  (стартовые монстры + кампания-боссы), арену, 1–2 модификатора.
- [ ] Таблица модификаторов (по образцу мутаторов из ROADMAP):
  низкая/высокая гравитация, лёд, гигантские головы, only-weapons,
  one-hit-KO, sudden death с 0 сек, зеркальный монстр (копия твоего).
- [ ] Одна зачётная попытка в день (переигровки — без рейтинга).
- [ ] Результат: время победы → локальная таблица личных рекордов
  (после Steam — leaderboard, см. `8-steam-port.md`).
- [ ] Кнопка «Бой дня» на главном экране с бейджем «не сыграно сегодня».

## 5.2 Стрики и календарь

- [ ] Счётчик дней подряд (день засчитан = сыгран бой дня).
- [ ] Награды за 3/7/14/30 дней: редкие цвета, лица, эффекты.
  **Закрыть часть существующей косметики под разблокировку** — сейчас все
  24 цвета и 28 лиц открыты сразу, коллекционировать нечего.
- [ ] Пропуск дня не сжигает стрик полностью (заморозка 1 раз в неделю) —
  жёсткие стрики вызывают выгорание и негативные отзывы.

## 5.3 Недельный босс

- [ ] Каждый понедельник — усиленный монстр с особым правилом
  («урон только по голове», «арена сжимается»).
- [ ] Медаль/косметика за победу, таблица времени убийства.

## 5.4 Ежедневный контракт мастерской

- [ ] Задание дня: «собери монстра ≤ N частей / только пружины / без брони —
  и победи чемпиона дня». Стимулирует главное УТП.
- [ ] Выполненный контракт = слот в «зале славы» (история своих билдов).

## 5.5 Прогрессия аккаунта (лёгкая)

- [ ] Уровень профиля: XP за бои (больше за бой дня/босса/контракт).
- [ ] Каждый уровень — косметическая награда или слот библиотеки.
- [ ] НЕ добавлять pay-to-win и гринд-стены — это пати-игра.

## 5.6 Инфраструктура

- [ ] Все награды/прогресс — в localStorage с версией схемы (этап 1),
  после Steam — Steam Cloud.
- [ ] Аналитика: локальный лог событий (день сыгран, стрик, контракт) —
  чтобы после релиза мерить ретеншен D1/D7/D30.

## Критерий готовности этапа

- Каждый день игра предлагает 3 вещи: бой дня, контракт, прогресс стрика.
- Есть ≥ 20 косметических наград, получаемых только через ежедневки.
- D1-ретеншен на плейтестах ≥ 40% (из 10 друзей 4 вернулись сами).
