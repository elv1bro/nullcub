# 3 — Мастерская → игра: замкнуть петлю творчества

Цель: всё, что игрок собирает в Blueprint Studio, реально работает в боях.
Это главное УТП игры («собери монстра/оружие/арену и дерись этим»).
Оценка: 1–2 недели.

## 3.1 Кастомное оружие в боях (сейчас — мёртвый груз)

Сохранённое оружие регистрируется один раз при старте приложения и никогда
не спавнится: все режимы используют hardcoded `DEFAULT_ARENA_ITEMS`.

- [ ] `src/items/registry.ts` ~32: register должен обновлять существующий ID
  (upsert), а не молча пропускать.
- [ ] Вызывать `registerCustomItems()` после каждого сохранения в мастерской.
- [ ] Собирать спавн-лист боя из дефолтных + кастомных предметов:
  `[...DEFAULT_ARENA_ITEMS, ...listBlueprints("item").map(toItemId)]`
  во всех режимах (LeveL1, 4FFA, Dedicated, NetBattleGuest, server/gameRoom).
- [ ] Экран выбора: перед боем игрок отмечает, какие предметы попадут в арену
  (дефолт: все).
- [ ] Кнопка **«Тест в бою»** в мастерской для kind=item: тренировочный бой,
  предмет спавнится рядом с игроком.

## 3.2 Кастомные арены (сейчас не используются вообще)

- [ ] Loader: перед боем читать arena-blueprint и спавнить его части как тела
  (с учётом `meta.static` — сейчас чекбокс «Закрепить» ничего не делает).
- [ ] Выбор арены перед боем (дефолтная коробка + сохранённые).
- [ ] Кнопка «Тест в бою» для kind=arena: спавн игрока в свою арену с ботом.
- [ ] Валидация арены: минимум пола/preграды, чтобы бойцы не проваливались.

## 3.3 Монстры (работает, углубить)

- [ ] Награда за победу над монстром: шанс дропа его части/оружия в библиотеку.
- [ ] «Паспорт монстра»: статистика побед/поражений своего монстра.
- [ ] Монстр против монстра: выбрать двух из библиотеки и смотреть бой (авто-битва).
  Дёшево и очень клипогенично.

## 3.4 Шеринг билдов (виральность)

- [ ] Экспорт/импорт блюпринта строкой (base64 JSON) — «скинь мне своего монстра
  в Discord». Без сервера.
- [ ] Позже (Steam): Workshop-интеграция — публикация блюпринтов
  (см. `8-steam-port.md`).

## 3.5 UX мастерской (доводка)

- [ ] Перемещение части не должно требовать скрытого «сначала выдели ПКМ»:
  LMB-drag за часть = перемещение; связь — отдельным модификатором
  (Shift+drag) или из режима «Связь».
- [ ] Показать подсказку `linkHint` в UI (ключ есть, не используется).
- [ ] Контролы для незадействованных полей меты предмета
  (`toughnessBonus`, `dropChanceMult`) — или удалить из типов.
- [ ] Undo/redo хотя бы на 10 шагов (сейчас нет — любое неверное удаление больно).

## Критерий готовности этапа

- Сделал оружие → через 30 секунд дерусь им в бою.
- Сделал арену → выбираю её перед любым локальным боем.
- Могу отправить монстра другу строкой, он импортирует и дерётся против него.
- В мастерской нельзя потерять работу одним misclick (undo).
