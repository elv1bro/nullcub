# 7 — Контент к релизу

Цель: достаточно разнообразия, чтобы отзывы не писали «контента на час».
Оценка: 2–4 недели, параллельно с этапами 5–6.

Текущий инвентарь: 1 арена, 4 оружия, 5 стартовых монстров, 6 глав кампании,
24 цвета, 28 лиц, 6 эффектов лица, 12 медалей.

## 7.1 Арены (сейчас 1 — критично мало)

- [ ] Минимум **6 играбельных арен** к релизу. Дёшево через геометрию + гиммик:
  - Колодец (узкая, высокие стены)
  - Мост (провалиться можно с двух сторон)
  - Качели (платформа на шарнире по центру)
  - Лёд (низкое трение)
  - Шипастая яма (шипы по краям — синергия с включёнными шипами из этапа 2)
  - Сжимающаяся арена (стены сходятся со временем — синергия с sudden death)
- [ ] Выбор арены перед боем + random.
- [ ] Кастомные арены из мастерской в этом же списке (этап 3).

## 7.2 Оружие (сейчас 4)

- [ ] До **10–12 предметов** с разными паттернами: двуручный молот (медленный,
  мега-отброс), кинжал (быстрый, слабый), щит (блок), бумеранг, рыба (пасхалка
  из ROADMAP «всё оружие — рыбы»), бомба с таймером.
- [ ] Каждому предмету — уникальный звук удара и частицы (клипогеничность).

## 7.3 Кампания

- [ ] Кампания «Вышибала» (6 глав) — довести до финала с боссом.
- [ ] Вторая кампания-«объявление» (5–7 глав) в другом сеттинге — по структуре
  из GAME_DESIGN (доска объявлений). Использовать монстров из мастерской
  как противников (глава = монстр-блюпринт + арена + модификатор).
- [ ] Комикс-заставки: хотя бы статичные панели с текстом между главами.

## 7.4 Монстры

- [ ] Стартовых монстров 5 → **12+** (разные архетипы: паук, змея, голем,
  вертолёт на пружинах — показать выразительность конструктора).
- [ ] Каждому — имя, реплика при появлении, особенность (быстрый/бронированный/
  взрывающийся).

## 7.5 Медали и косметика

- [ ] Медалей 12 → 25+ (за оружие, за арены, за монстров, за стрики).
- [ ] Косметика за прогресс (этап 5): 10+ закрытых цветов/лиц/эффектов.
- [ ] Killcam-рамки/фильтры для клипов как награды.

## 7.6 Звук и музыка (сейчас слабое место для Steam)

- [ ] Музыка: меню + 2–3 боевых трека (лицензионно чистые).
- [ ] Диктор: «FIGHT», «K.O.», «PLAYER ONE WINS» (ROADMAP этап 4).
- [ ] Пройтись по всем событиям: у каждого удара/подбора/победы есть звук.

## Критерий готовности этапа

- Плейлист «каждый бой на новой арене» не повторяется 6 боёв.
- 2 кампании проходятся за 2 вечера.
- Стример на 2-часовом стриме не увидит весь контент.
