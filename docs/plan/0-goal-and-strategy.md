# 0 — Цель и стратегия

## Цель

Выпустить игру в Steam и удерживать **1000+ игроков в день (DAU)**.

## Честная математика воронки

1000 DAU — это много. Для платной инди-игры DAU ≈ 1–3% от общего числа владельцев,
то есть нужно **50 000–100 000 продаж**. Реалистичный путь — не «продать сразу», а:

```
Бесплатная веб-версия (вирус) → Wishlist в Steam → Демо / Next Fest →
Релиз (платный или F2P+косметика) → Ретеншн-системы удерживают DAU
```

Опорные точки:
- **10 000 wishlist** до релиза → Steam покажет игру в «Популярные предстоящие» → органика.
- Конверсия wishlist → покупка в первую неделю: 10–20%.
- Виральность — главный бесплатный канал: клипы со смешными рэгдоллами и лицами
  игроков с вебки. Каждая фича проверяется вопросом «станет ли клип смешнее?».

## Три столпа, на которых держится DAU

| Столп | Что даёт | Состояние сейчас |
|---|---|---|
| **Сессионный фан** | Игрок получает удовольствие за первые 60 секунд | Ядро боя есть, но баги ломают ощущения (см. `1-stabilize.md`) |
| **Творчество** | Мастерская: монстры, оружие, арены → делиться билдами | Редактор есть, но оружие/арены не попадают в бой (см. `3-workshop-to-game.md`) |
| **Ежедневный повод зайти** | Бой дня, стрики, недельный босс | Отсутствует полностью (см. `5-retention.md`) |

## Определение «готово» для всего проекта

- Новый игрок без объяснений получает первый смешной момент за < 2 минуты.
- Два человека в разных городах играют по ссылке/инвайту без танцев с бубном.
- Есть причина зайти завтра (бой дня / стрик / незакрытая цель).
- Из любого боя можно получить клип, который не стыдно кинуть в чат.
