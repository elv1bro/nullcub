# Трейлеры для Steam: съёмка игрой и монтаж по JSON

Ролики снимает сама игра. Каждый план запускается в окне Godot под Movie Maker (`--write-movie`, `--fixed-fps`). Кадры получаются ровными, даже если машина рисует медленнее реального времени. Потом `trailer.py` режет и склеивает планы по списку из JSON, накладывает надписи и музыку и проверяет файл под требования Steam. План и раскадровка — `docs/plan-demo/STEAM_TRAILER.md`.

```bash
python3 godot/tools/trailer/trailer.py all                    # снять, смонтировать, проверить (teaser.json, язык из JSON)
python3 godot/tools/trailer/trailer.py all --lang en          # английская версия: планы снимаются с английским HUD (shots/<id>_en), русские остаются
python3 godot/tools/trailer/trailer.py shoot --only ruins_ko --force   # переснять один план
python3 godot/tools/trailer/trailer.py all --seq godot/tools/trailer/<другой>.json
```

Результат лежит в `test-artifacts/trailer/<name>/` (в git не попадает):
- `<name>_<lang>.mp4` — готовый ролик (1920×1080, 60 к/с, H.264 + AAC, −14 LUFS);
- `check_<lang>.json` — результаты проверок;
- `micro_<lang>.png` — 6 кадров из разных мест ролика. Steam сам режет из первого трейлера 6 кусков по 1 с для превью, поэтому каждый кусок должен читаться отдельно;
- `edit_<lang>.json` — что куда встало (секунда, план, сид, надпись);
- `shots/<id>_<язык>.avi` и `.json` — снятые планы (как записал Movie Maker) и их события.

Снятый план не переснимается, пока не поменялось его описание (или `trailer_shot.gd`). Поэтому правка порядка, длины или надписи — это только монтаж: ~40 с на 22-секундный тизер. Ролик собирается одним проходом ffmpeg прямо из AVI. По умолчанию кодер аппаратный (VideoToolbox, `render.bitrate` 40M): ffmpeg на этой машине — x86 под Rosetta, и x264 медленный. `"encoder": "x264"` в `render` — лучше на бит, но в разы дольше.

## Как поменять ролик — правка `teaser.json`

| Что поменять | Где |
|---|---|
| порядок склеек | переставить строки в `edit` |
| длина куска | `len` (секунды в готовом ролике) |
| откуда резать | `at` — событие-якорь, `from` — сдвиг от него в секундах (минус — раньше) |
| надпись | `text` — ключ из `texts`, или сразу строка |
| перевод надписи | `texts.<ключ>.<язык>` |
| замедление | `speed` (0.5 — вдвое медленнее; для плавности сними план с `"fps": 120`); звук такого куска выключается |
| другой бой | `shots.<id>.seed` — список сидов, берётся первый, где случились все события из `require` |
| музыка | `audio.music`, `music_start`, `music_db`; громкость игры — `game_db` |
| финальная плашка | `edit: {"card": "end", "len": 5}` + `end_card` (знак, строка, призыв) |

Якоря `at`:
- `fight` — начало боя;
- `start` — первый кадр записи;
- число — секунда записи;
- тип события — первое такое событие; `тип#N` — N-е по счёту.

Типы событий:
- `hit` — любой удар; уровни удара `light`, `heavy`, `crit`, `ko_crit`;
- `ko` — нокаут;
- `slam` — удар о стену;
- `break` — сломан сустав; `detach` — отлетела деталь;
- `over` — конец матча.

## Поля плана (`shots.<id>`, недостающие берутся из `defaults`)

| Поле | Что делает |
|---|---|
| `scene` | `null_hall` (купол Быстрого боя), `scrap`, `ruins`, `void`, `workshop` или `res://…` |
| `seed` | число или список (дубли) |
| `hud`, `hud_skin` | HUD вкл/выкл; `neon` / `broadcast` / `led`. Служебные подсказки клавиш скрыты всегда |
| `bots` | `{"p1": 3, "p2": 3}` — уровни RivalBrain 1–4 для обеих сторон |
| `brain` | свойства обоих ботов, напр. `{"retreat_s": 0.7}` — меньше отходят, больше дерутся |
| `camera` | свойства DynamicCamera, напр. `{"max_half_height": 6.5}` — ближе |
| `modes` | `{"joint_break": true, "drive": false}` — суставы рвутся (клавиша C в игре), ДРАЙВ (J) |
| `force` | `[{"at": 2.0, "tier": "crit"}]` — следующий удар после 2 с боя будет критом |
| `hp` | `{"p2": 25}` — запас HP на старте (нокаут быстрее) |
| `spawn` | `{"p1": [-2, 0.05], "p2": [2, 0.05]}` — точки появления |
| `length` | сколько секунд боя снимать; или `until` (событие) + `tail` (сколько после него) |
| `max_s` | потолок записи от начала боя |
| `require` | какие события обязаны случиться, иначе пробуется следующий сид |
| `gfx`, `ssaa`, `msaa` | пресет графики (по умолчанию `ultra`), суперсэмплинг 3D (1.5 = рендер в 1.5× и сведение), MSAA |
| `fps` | частота записи плана (по умолчанию из `render`) |
| `crowd`, `music`, `countdown`, `lang` | толпа, музыка игры (обычно выкл — музыку кладёт монтаж), отсчёт, язык HUD |

Настройки автора (`user://*.cfg`) съёмка не трогает: скин, язык, графика и звук меняются только в памяти.

## Проверки `check`

Проверяется:
- разрешение и 16:9, 30/60 к/с, H.264 yuv420p, AAC 44.1/48 кГц стерео, битрейт ≥ 5000 кбит/с — требования Steamworks;
- длина равна сумме склеек;
- нет черноты ≥ 0.4 с и застывания ≥ 1 с вне плашки;
- громкость −14 ± 1.5 LUFS, true-peak ≤ −1 dBTP;
- в надписях нет «Ragdoll Master» (BRAND.md).

Выход 0 — всё прошло.
