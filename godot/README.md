# Ragdoll Master Demo — Godot 4.7 + Jolt

Демо-проект по плану `../docs/plan-demo/` (правила: `ASSET_PIPELINE.md`). Запуск игры: `godot --path godot` или ярлык `~/Desktop/Ragdoll Master.app`. Редактор: `godot --path godot -e`.

Главная сцена `scenes/playground.tscn`: арена «Руины» + две куклы + оружие + динамическая камера + `Match` (бой: HP, урон, KO, Sudden Death, итоги) + `HUD`. `scenes/playground_workshop.tscn` — то же на арене «Мастерская», `scenes/playground_void.tscn` — пустое чёрное поле «Void» как в Ragdoll Masters (без оружия, для проверки механики). P1 WASD + Shift (рывок) + Space (переворот), P2 стрелки + правый Ctrl + Enter, R заново (`Match.restart()`), 1 / 2 / 3 — Руины / Мастерская / Void, Esc выход.

## Структура

- `scenes/doll/doll.tscn` (клён) и `doll_dark.tscn` (орех) — кукла v3: 14 RigidBody3D + 13 суставов + меши художественного манекена (`assets/models/heroes/mannequin_v3/`, R22); `doll.gd` только поведение (управление, мышцы, стан). Пересборка: `godot --headless --path . -s res://tools/build_doll_scene.gd`.
- `scenes/arena/ruins.tscn` — арена, собранная из компонент-сцен `scenes/props/*` (бочка/ящик разрушаемые, мост, флаги, ворота, блоки, факел, клетка) + `scenes/arena/parallax_background.tscn` (4 слоя R18). `ruins.gd` — точки спавна, границы, сигнал падения. Пересборка: `-s res://tools/build_arena_ruins.gd`. `scenes/arena/workshop.tscn` — арена «Мастерская» (R22) из `scenes/props/workshop_*` (пол, верстаки, штабели, полки, станок, козлы, лампы на цепях, окна); пересборка: `-s res://tools/build_workshop_props_scenes.gd`, затем `-s res://tools/build_arena_workshop.gd`.
- `scenes/arena/void.tscn` — арена «Void» (RM): серый пол 16 м, тёмные стены x=±7, невидимый потолок y=8, чёрный задник с едва видной сеткой (unshaded), `assets/environments/void_env.tres` (чёрный фон, ambient + слабое солнце + контровой, без тумана/SSAO/DOF), спавны x=±3 и ±5.5. `void.gd` — `spawn_points()`, `bounds()` (−7..7 × −0.4..8), сигнал `body_fell` (не испускается). Модели: `tools/blender/arena_void.py` → `assets/models/arena/void/{Floor_Slab,Wall_Side,Grid_Backdrop}.glb` + тайл сетки `assets/textures/pbr/grid_void/albedo.png`; пересборка сцены: `-s res://tools/build_arena_void.gd`.
- `scripts/core/` — бой: `damage.gd` (формула и калибровка), `doll_combat.gd` (детектор ударов, ребёнок куклы), `match.gd` (фазы, таймеры, KO, Sudden Death, итоги, hit feel). `scenes/ui/` — HUD по R20: `hud.tscn` (`Hud.bind(match)`), панели игроков, диктор, карточка KO, итоги; текстуры `assets/ui/` (`gen_ui_textures.py`).
- `scenes/weapons/weapon_<id>.tscn` — оружие (hammer, mace, sword, axe, pan); `weapon_pickup.gd` — автоподбор в руку. Пересборка: `-s res://tools/build_weapon_scenes.gd`.
- `scenes/camera/dynamic_camera.gd` — камера по правилам концепта §7. `scenes/lookdev/workshop_lookdev.tscn` — лук-дев мастерской (свет R22), `scenes/fx/` + `scripts/fx/impact_fx.gd` (+ `impact_flash.gd`) — вспышка (цвет по типу удара), щепки и пыль при ударе, `assets/environments/*.tres` — пресеты окружения.
- `scripts/tuning.gd` — все числа баланса (autoload `Tuning`). `scripts/input/input_setup.gd` — действия p1..p4.
- `tools/blender/*.py` — исходники моделей (Blender 4.5 headless): `textures.py` (запечённые PBR в `assets/textures/pbr/`), `wooden_doll_v3.py` (кукла, `-- tone=light|dark`), `props.py`, `weapons.py`, `workshop_props.py`, `arena_void.py` (арена Void), старые `mannequin.py`/`arena_kit.py`, хелперы `common.py`. Запуск: `/Applications/Blender.app/Contents/MacOS/Blender -b --python godot/tools/blender/<script>.py`.
- `assets/models/heroes/mannequin/`, `assets/models/arena/`, `assets/models/weapons/` — экспортированные glb.
- `_legacy/` — старые болванки и генераторы, не импортируются.

## Проверки

```bash

godot/tests/run_gate.sh                         # гейт куклы: doll_gate (9 проверок) + feel_probe strict=1 (99 целей / 73 проверки, FEEL_TARGET §7 и §9–9.3), отчёты tests/doll_gate_report.json, tests/feel_probe_report.json
gtimeout 3000 /usr/bin/arch -arm64 /bin/bash godot/tests/run_gate.sh   # то же из-под x86_64-обёртки gtimeout: arch -arm64 обязателен (иначе Godot идёт через Rosetta); так же run_combat_gate.sh и `gtimeout N /usr/bin/arch -arm64 /usr/local/bin/godot …` для любой сцены ниже
godot --path godot --resolution 1280x720 res://tests/doll_snapshot.tscn      # манекен спереди + в полёте

godot --headless --path godot --fixed-fps 60 res://tests/feel_probe.tscn -- "strict=1"          # feel куклы числами (override: zeta=, hz=, k_<Group>=, t_<Group>=, z_<Group>= (ζ группы), f_<Group>= (трение), ld= (FLIGHT_LINEAR_DAMP), gap= (зазор рывка), v6.2 дамп без правки Tuning: ldc=/ldl= (ядро/конечности), adl= (угловой конечностей), fdc=/fdl= (в полёте), brake= (IDLE_BRAKE_DAMP), v7: adc= (угловой ядра), hms=/hmh=/hmr=/hmf= (обмякание при ударе: множитель/держать/возврат/трение), hmg=Shoulder|Hip (группы), p_<Group>= (угол позы), trace=1 (печать рядов), report=<абс. путь JSON>, only=a|b): поза покоя, возврат пружин, kick, hover, move, отскок; v6 — полёт после удара hit_flight_10/hit_flight_30/hit_rush/hit_dash, v6.2 hit_clash (встречный наскок: разлёт sep_0p6s ≥ 2.7 м, отход бьющего attacker_vx_0p3s ≤ 0.5, складывание limb_fold_deg ≥ 35°) и запаздывание конечностей lag_thrust_x/lag_thrust_y/lag_flip/lag_spin, v7 lag_dash, складывание hit_flight_10 за 0.4 с и возврат, weapon_arm (рука с оружием жёстче, после drop — значения группы), стойка по порогам RM → tests/feel_probe_report.json (strict=1 — цели feel валят exit)
godot --path godot --resolution 1280x720 --always-on-top res://tests/hud_snapshot.tscn -- "players=2"   # HUD со стабом Match
godot --path godot --resolution 1280x720 --always-on-top res://tests/fx_probe.tscn                       # вспышка/щепки: 3 вспышки на 0.12 с, tests/fx_probe_{a,b}.png
godot --path godot --resolution 1920x1080 --always-on-top res://tests/playground_snapshot.tscn -- "hit=1,ko=1"   # кадры боя/KO/итогов (+ scene=workshop|void, pit=1; в режиме удара P2 делает рывок, dash=0 — прежний толчок)
godot --path godot --resolution 1280x720 --always-on-top res://tests/void_snapshot.tscn   # Void: ../docs/plan-demo/img/05-void-v6-{close,wide}.png + числа (кадр RM: кукла ≥ 0.28 кадра на спавне, отъезд до всего поля, кадр в границах; фон чёрный, сетка едва видна, куклы читаются), tests/void_snapshot_report.json
godot --path godot --resolution 1920x1080 res://tests/perf_probe.tscn -- "secs=8,scene=void,min_fps=59"   # FPS по секундам; min_fps — exit 1 ниже порога

```

Производительность на Apple M2 при 1080p: 60 fps на всех трёх аренах (потолок vsync). 28.09 (интеграция I) на батарее в Low Power Mode при load average 4–24 от параллельных сессий: Void 60 fps, Руины 17–30, Мастерская 23–32 — перемерить от сети без нагрузки. 28.09 (I1) при load average ~135: Void 57.1 fps, минимум 50.3; (I2) при load 10–17: Void 60.0 fps, минимум 59.9; (I3, окно 1280×720) при load 6–7: Void 72.4 fps, минимум 71.4. Godot из-под x86_64-обёрток (`gtimeout`) запускать через `/usr/bin/arch -arm64`, иначе Rosetta → MoltenVK.
