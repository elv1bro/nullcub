# Сэмплы WsSfx (тактильные звуки мастерской)

`scenes/workshop/ws_sfx.gd` печёт звуки интерфейса мастерской из этих записей (дерево «ток», скрип волокна, вух) плюс синтез.
Файлы лежат отдельно от `assets/audio/sfx/` (слои боя): переработка боевого звука (380abb2) удалила `sfx/tok` и `sfx/creak/fiber_creak_*` и
подменила `sfx/whoosh/*`, из-за чего слои «ток» пропали, а `tests/ws_sfx_probe.gd` стал красным (варианты кнопки одинаковые, громкость щелчков вразнобой).
Содержимое — как до 380abb2 (ogg 1:1). Лицензии — как у остальных слоёв (CC0, assets/audio/LICENSES.md, слои tok / creak / whoosh прежнего набора).
